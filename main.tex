\begin{abstract}
The rapid proliferation of enterprise large language model (LLM) serving and autonomous multi-agent swarms has collided with an operational ceiling: the \textit{LLM Token Economics and Attention Wall}. In production deployments across cloud accelerators, up to 35\% of ingested tokens represent synthetic subword tokenizer fragmentation artifacts and low-information conversational boilerplate. This token bloat incurs high financial inference costs, induces copy-on-write page duplication on unaligned trailing Key-Value (KV) cache blocks, and causes attention dispersion across Transformer self-attention heads, precipitating silent hallucinations. In this paper, we present the \textit{Tokenomics Compiler} (\texttt{PromptVM}), a deterministic, hardware-grounded compilation framework and discrete-choice economic router for LLM serving. Our system: (1) parses structured schemas into Abstract Syntax Trees (ASTs) and transpiles them into subword-minimal serializations over a bounded candidate space ($|\mathcal{S}_{\text{dense}}| \le 8$) using quotation-synchronized delta-tokenization while preserving both formal JSON Schema validation contracts and task-semantic parameter role disambiguation; (2) performs sub-clause pleasantry and duplicate-signature span stripping alongside inverse-length-scaled empirical invariant density scoring to prune diffuse conversational verbiage while unconditionally retaining modal and relational invariants; (3) injects uppercase structural landmark anchors with empirical attention affinity boost ($\gamma > 1$), mathematically proving that landmark anchors bound self-attention entropy on dispersive heads ($\mathcal{H}(\mathbf{a}_i) \le \mathcal{H}_{\max}(i, K, \gamma) < \ln i$ with $\frac{\partial\mathcal{H}_{\max}}{\partial\gamma} < 0$ for all $\gamma > 1$) while co-locating retained constraint predicates to amplify retrieval-head attention by $2.8\times$; (4) enforces physical KV-cache boundary-page sealing ($|\mathcal{P}_{\text{prefix}}| \equiv 0 \pmod B$, $B \in \{16, 32\}$) via server-side JAX/Pallas VMEM causal bitmasking and decoupled RoPE logical positions to eliminate multi-branch copy-on-write page duplication on self-hosted Google Cloud TPU v6e Trillium accelerators; and (5) solves a constrained discrete-choice Pareto optimization across heterogeneous model serving tiers (evaluated across internal harness routing tiers Gemini 3.8 Flash, Gemini 3.8 Flash with dynamic test-time reasoning tokens, and Gemini 4.0 Argon, mapped to production Vertex AI Flash and Pro endpoints). Across $N = 1{,}000$ enterprise traces evaluated across 5 distinct operational cohorts (and validated on public BIRD-SQL and BFCL benchmarks), our compiler achieves a 1.11\% to 53.47\% per-cohort token reduction (17.52\% pooled global reduction, saving 81,800 tokens per 1,000 requests; 39.98\% on structured prompt cohorts), slashes blended inference invoice costs by 39.44\% (up to 88.79\% in database queries), and reduces P95 latency by 38.85\% against baseline (27.98\% against naive regex trimming) while achieving a 99.70\% strict first-attempt Turn-1 Pass@1 (vs.\ 85.00\% Turn-1 and 98.50\% post-retry on monolithic Argon) and 100.00\% post-verification workflow completion rate.
\end{abstract}

\section{Introduction}
\label{sec:intro}
The industrial transition from basic conversational chat interfaces to high-throughput autonomous multi-agent swarms has fundamentally transformed cloud inference demand. Enterprise platforms such as Google Cloud Vertex AI, the Google Agent Development Kit (ADK; \url{https://cloud.google.com/vertex-ai/docs/agent-builder}), and the Model Context Protocol (MCP; \url{https://modelcontextprotocol.io}) orchestrate millions of daily reasoning-and-acting invocations \cite{yao2023react, patil2024gorilla} wherein software agents query distributed databases, validate OpenAPI endpoints, inspect source repositories, and reconcile financial ledgers.

Despite rapid advancements in accelerator throughput and distributed inference scaling \cite{jouppi2023tpu, pope2023efficiently} (spanning Google Cloud TPU v4 supercomputing pods \cite{jouppi2023tpu} and Cloud TPU v6e Trillium accelerators; \url{https://cloud.google.com/tpu/docs/v6e-overview}), enterprise deployments face an acute economic and physical bottleneck: the \textit{LLM Token Economics and Attention Wall}. Unmanaged prompt construction introduces severe systemic inefficiencies across three distinct operational layers:
\begin{enumerate}
    \item \textbf{The Subword Fragmentation Tax:} Standard subword tokenizers---operating either via SentencePiece Unigram subword segmentation in Gemini and Gemma \cite{kudo2018unigram, gemini2024, gemma2_2024} or iterative Byte-Pair Encoding (BPE) pair merges---decompose unaligned whitespace, camelCase identifiers, and pretty-printed JSON schemas \cite{bray2017rfc8259} into multiple fragmented subword tokens. In enterprise schemas, up to 35\% of ingested tokens represent structural formatting overhead rather than semantic domain entropy.
    \item \textbf{Attention Dispersion and Hallucination:} Transformer self-attention layers compute softmax-normalized dot products over query-key pairs \cite{vaswani2017attention}. When prompts are laden with verbose conversational filler, the attention probability mass disperses broadly across keys, driving the Shannon attention entropy toward its theoretical maximum $\ln i$. This dispersion dilutes attention weights on negative constraints and schema contracts, causing critical parameters to be hallucinated or omitted.
    \item \textbf{Hardware KV-Cache Boundary-Page Copy-on-Write Duplication:} Production serving runtimes (e.g., vLLM \cite{kwon2023vllm}, SGLang \cite{zheng2024sglang}, and JAX/Pallas Block-Attention kernels \cite{bradbury2018jax}) manage persistent Key-Value (KV) cache memory in discrete virtual memory pages of block size $B = 16$ or $32$ tokens in High Bandwidth Memory (HBM2e). When shared static prompt prefixes terminate at non-page boundaries ($|\mathcal{P}_{\text{prefix}}| \not\equiv 0 \pmod B$), appending branch-specific dynamic suffix tokens into the unsealed trailing prefix block forces copy-on-write (CoW) page duplication and K/V recomputation across concurrent subagent execution branches.
\end{enumerate}

To overcome these deficiencies, we introduce the \textit{Tokenomics Compiler} (\texttt{PromptVM}), a deterministic hardware-aware systems framework that bridges the semantic instruction layer with physical accelerator memory topologies. Rather than relying on fragile, heuristic prompt engineering, our framework formalizes a five-stage compilation and routing pipeline: (1) Tokenizer-Aware AST Transpilation, (2) Information-Theoretic Entropy Compaction, (3) Attention-Sink Structural Landmark Anchoring, (4) Hardware Paged-Cache Block Boundary Alignment, and (5) Discrete-Choice Pareto Economic Routing.

The primary technical contributions of this work are as follows:
\begin{itemize}
    \item We formalize \textbf{AST Subword Merge Optimization} over OpenAPI and JSON schemas \cite{bray2017rfc8259} across a bounded $2^3=8$-candidate AST space using quotation-synchronized delta-tokenization and exact full-sequence verification, eliminating synthetic tokenization artifacts under formal validation-contract equivalence while preserving task-semantic parameter role disambiguation.
    \item We define \textbf{Sub-Clause Span Stripping and Invariant Density Scoring} ($\mathcal{D}_{\text{inv}}(\tilde{c}_k)$) with inverse-length threshold scaling and polarity-aware relational predicate signature extraction ($\operatorname{Sig}(c_k)$) to prune conversational noise while unconditionally retaining novel modal and relational constraints regardless of clause length.
    \item We prove \textbf{Theorem 1}, demonstrating that uppercase structural landmark anchors acting as artificial attention sinks with affinity boost $\gamma > 1$ strictly bound query self-attention entropy on dispersive heads ($\mathcal{H}(\mathbf{a}_i) \le \mathcal{H}_{\max}(i, K, \gamma) < \ln i$) with $\frac{\partial\mathcal{H}_{\max}}{\partial\gamma} = -\frac{K(i-K)\ln\gamma}{Z_i^2} < 0$, where $Z_i = K\gamma + (i - K)$, while physical co-location boosts retrieval-head constraint attention by $2.8\times$.
    \item We co-design a \textbf{Client-Server Paged-Cache Topologist} that aligns static prefixes to physical page boundaries ($|\mathcal{P}_{\text{prefix}}| \equiv 0 \pmod B$) with server-side Pallas VMEM causal bitmasking and logical RoPE/window decoupling to seal boundary pages for zero-copy multi-agent sharing on self-hosted Cloud TPU v6e clusters.
    \item We construct a \textbf{Discrete-Choice Pareto Economic Router} that jointly optimizes model tier selection across heterogeneous serving tiers (Gemini 3.8 Flash, Gemini 3.8 Flash-Thinking, and Gemini 4.0 Argon mapped to Vertex AI Flash/Pro endpoints) and dynamic test-time reasoning tokens via an exact closed form.
    \item We evaluate our system across 5 seeds on $N = 1{,}000$ enterprise traces spanning 5 cohorts and 400 public benchmark tasks (BIRD-SQL \cite{bird2023} and BFCL \cite{patil2024gorilla}), demonstrating a 1.11\% to 53.47\% enterprise token reduction (17.52\% pooled mean, 39.98\% on structured cohorts), 39.44\% net cost savings (up to 88.79\% in SQL), 99.70\% strict Turn-1 Pass@1, and 100.00\% post-verification workflow completion.
\end{itemize}

\section{Background and Systems Architecture}
\label{sec:background}

\subsection{Transformer Self-Attention Physics and Dispersion}
In standard multi-head self-attention, during the prompt prefill phase over a sequence of $N$ tokens, the attention weight matrix at layer $l$ and head $h$ is:
\begin{equation}
\label{eq:attention_matrix}
\mathbf{A}^{(l,h)} = \operatorname{softmax}\left(\frac{\mathbf{Q}^{(l,h)}(\mathbf{K}^{(l,h)})^T}{\sqrt{d_{\text{head}}}} + \mathbf{M}\right) \in \mathbb{R}^{N \times N}
\end{equation}
(omitting layer and head superscripts $(l,h)$ below for brevity), where $d_{\text{head}}$ denotes the key projection dimension, and $\mathbf{M} \in \{0, -\infty\}^{N \times N}$ is the causal attention mask enforcing $M_{ij} = 0$ for $j \le i$ and $M_{ij} = -\infty$ for $j > i$ in decoder-only autoregressive architectures (including Gemini and Gemma). Consequently, for any prefill query position $i \le N$ (or subsequent autoregressive decode step $i = N + t$ attending over the $i$ accumulated context keys), query token $i$ can attend only to antecedent positions $1 \le j \le i$, and its attention vector $\mathbf{a}_i = (A_{i1}, \dots, A_{ii})$ lies on the restricted simplex $\Delta^{i-1}$ where $\sum_{j=1}^i A_{ij} = 1$. The Shannon entropy of this distribution is:
\begin{equation}
\label{eq:entropy_def}
\mathcal{H}(\mathbf{a}_i) = - \sum_{j=1}^i A_{ij} \ln A_{ij}
\end{equation}
When the input context consists of diffuse natural language, query-key affinities exhibit low variance, causing the softmax distribution to approach the uniform distribution with maximal theoretical entropy $\mathcal{H}_{\text{diffuse}} \le \ln i$. While initial sequence tokens (such as \texttt{<bos>} at $j=1$) act as natural emergent sinks \cite{xiao2023streamingllm}, unstructured text dilutes the attention weights allocated to sparse critical constraints (e.g., \texttt{status = 'ACTIVE'}), decaying as $\mathcal{O}(1/i)$ and precipitating retrieval failure and hallucinations. In PromptVM's compiled token layout, the shared static prefix $\mathcal{P}_{\text{prefix}}$ (containing the static system preamble and Stage 1 transpiled schema $S^*$ at indices $\{1, \dots, |\mathcal{P}_{\text{prefix}}|\}$) and optional Stage 4 boundary padding $\mathcal{I}_{\text{pad}}$ (of size $\Delta_{\text{frag}}$ on TPU v6e) are serialized ahead of the request-dynamic suffix, which begins with the $K=7$-token Stage 3 landmark header at indices $\mathcal{S} = \{|\mathcal{P}_{\text{prefix}}| + \Delta_{\text{frag}} + 1, \dots, |\mathcal{P}_{\text{prefix}}| + \Delta_{\text{frag}} + K\}$ followed immediately by the co-located Stage 2 invariant clauses $\mathcal{I}_{\text{inv}}$ and terminal task query. Under causal masking, for all subsequent query positions $i > |\mathcal{P}_{\text{prefix}}| + \Delta_{\text{frag}} + K$ across the invariant block, task query, and decode steps, the entire landmark header lies in the active antecedent subset $\mathcal{S}_i = \mathcal{S} \subset \{1, \dots, i-1\}$ of size $K = |\mathcal{S}_i|$ ($0 < K < i \le N$), with the terminal prompt prefill token ($i = N$) satisfying the global prefill bound $\mathcal{H}_{\max}(N, K, \gamma) < \ln N$ while keeping $\mathcal{P}_{\text{prefix}}$ purely static and shareable across concurrent subagents.

\subsection{Subword Tokenization Mechanics}
Modern LLMs utilize subword tokenizers parameterized by a vocabulary graph $\mathcal{V}$ containing $|\mathcal{V}| \approx 256{,}000$ subword tokens. Tokenizers operate either via SentencePiece Unigram subword segmentation (which optimizes emission probabilities over training text via Expectation-Maximization and resolves sequence segmentation via Viterbi decoding over a candidate lattice \cite{kudo2018unigram, gemini2024}) or Byte-Pair Encoding (BPE, performing greedy bottom-up merge operations over frequent adjacent character or byte pairs). Consequently:
\begin{itemize}
    \item Structural whitespace (e.g., 4-space JSON indentation) decomposes into 2 to 4 distinct tokens per line.
    \item Compound and camelCase identifiers decompose across case boundaries and subword roots; for example, \texttt{EnterpriseOrderSystem} decomposes into 3 tokens: \texttt{['Enterprise', 'Order', 'System']}, while identifiers with non-dictionary prefixes fracture into numerous unaligned fragments.
    \item Redundant schema descriptions (\texttt{"description": "A parameter representing..."}) inject dozens of low-entropy tokens that consume prompt sequence budget.
\end{itemize}

\subsection{Hardware Memory Hierarchy on TPU v6e Trillium}
Building on the systolic array and high-bandwidth memory architecture established in earlier TPU generations \cite{jouppi2023tpu, pope2023efficiently}, Google Cloud TPU v6e (Trillium; \url{https://cloud.google.com/tpu/docs/v6e-overview}) decouples computation and memory into Matrix Multiply Units (MXUs), Vector Processing Units (VPUs), 32 GB of High Bandwidth Memory (HBM2e delivering $\approx 1{,}640\text{ GB/s}$ bandwidth), and on-chip Vector Memory (VMEM). To maximize systolic array utilization, serving engines manage the persistent Key-Value (KV) activation cache in off-chip HBM2e using PagedAttention \cite{kwon2023vllm}, partitioning memory into physical blocks of size $B = 16$ or $32$ tokens, while VMEM serves as a scratchpad for staging activation tiles during JAX/Pallas kernel execution \cite{bradbury2018jax}. When shared static prompt prefixes terminate at non-page boundaries ($|\mathcal{P}_{\text{prefix}}| \not\equiv 0 \pmod B$), the trailing partial page block has an unaligned slot deficit:
\begin{equation}
\label{eq:delta_frag}
\Delta_{\text{frag}} = (B - (|\mathcal{P}_{\text{prefix}}| \bmod B)) \bmod B
\end{equation}
Crucially, we distinguish between \textit{single-copy physical slot occupancy} and \textit{multi-branch copy-on-write (CoW) page sealing}. Within a single prefix instance, antecedent full blocks are already shared zero-copy in PagedAttention \cite{kwon2023vllm}, whereas the unaligned terminal block holds $B - \Delta_{\text{frag}}$ payload tokens (e.g., across a typical 134-token static prefix spanning $\lceil 134/16\rceil = 9$ blocks of size $B=16$, total multi-page payload utilization is $134/144 = 93.06\%$, or $91.40\%$ pooled across enterprise schemas). However, when $M_{\text{branch}}$ concurrent subagents append branch-specific dynamic suffix tokens to an unsealed trailing prefix block, standard serving runtimes must either duplicate and recompute the $B - \Delta_{\text{frag}}$ prefix keys across all $M_{\text{branch}}$ branches via copy-on-write or support custom interior block masking. In self-hosted serving runtimes on Cloud TPU v6e clusters, Stage 4 pads the terminal prefix block by $\Delta_{\text{frag}}$ masked slots to seal the boundary page as read-only ($\Delta_{\text{frag}} \equiv 0 \pmod B$), eliminating $M_{\text{branch}}$-way CoW duplication while keeping single-copy payload occupancy unchanged. On managed Google Cloud Vertex AI endpoints, physical page tables are abstracted; Stage 4 prefix padding is bypassed for standard sub-32k requests (avoiding any billable token addition), while coordinating with Vertex AI Context Caching for static prefixes exceeding the 32,768-token threshold.

\section{Mathematical Formulation and Methodology}
\label{sec:methodology}

\subsection{Tokenizer-Aware AST Transpiler}
Let $\Sigma^*$ be the set of Unicode character sequences, and let $T_M : \Sigma^* \to \mathcal{V}_M^*$ denote the target model's native tokenizer projection (invoking SentencePiece Unigram Viterbi decoding for Gemini/Gemma models \cite{kudo2018unigram, gemini2024} or BPE merge tables when cross-compiling for external model families). Given an enterprise execution request comprising an unstructured instruction $I$ and a structured schema contract $S \in \mathcal{T}_{\text{schema}}$, standard serialization produces raw token count $|T_M(I \circ S)|$.

The Tokenizer-Aware AST Transpiler constructs an Abstract Syntax Tree $\mathcal{T}_{\text{AST}}(S)$ and applies a contract-preserving projection $\phi : \mathcal{T}_{\text{AST}} \to \Sigma^*$ defined over a finite candidate family of dense canonical AST serializations $\mathcal{S}_{\text{dense}}$ ($|\mathcal{S}_{\text{dense}}| \le 8$):
\begin{equation}
\label{eq:ast_min}
S^* = \phi(\mathcal{T}_{\text{AST}}) = \arg\min_{S' \in \mathcal{S}_{\text{dense}},\, S' \equiv_{\text{sem}} S} |T_M(S')|
\end{equation}
We explicitly distinguish between \textit{formal syntactic JSON Schema validation-contract equivalence} ($S' \equiv_{\text{sem}} S$, meaning $S'$ accepts the exact same set of valid JSON/OpenAPI payload instances as $S$, preserving all parameter identifiers, primitive types, \texttt{enum} sets, and \texttt{required} arrays) and \textit{task-semantic parameter disambiguation} (preserving domain role and unit semantics required by the LLM to synthesize accurate tool arguments; note that while decode-time grammar masking such as SGLang \cite{zheng2024sglang} enforces output JSON syntax during decoding, Stage 1 targets in-context prompt serializations in $\mathcal{P}_{\text{prefix}}$ to reduce prefill token billing and HBM KV-cache footprint while preserving semantic constraints).

To guarantee zero loss of task-semantic parameter disambiguation prior to pruning any \texttt{description} field exceeding length threshold $\ell_{\max} = 40$ characters, the transpiler executes a four-part deterministic guard (where any description $> 40$ characters matching Guards 1--3 is compressed by stripping the exact static 75-word English function/filler stopword set $\mathcal{W}_{\text{stop}}$ while retaining all non-stopword content tokens and matched constraint spans in full, supplemented by a conservative $\mathcal{O}(|d|)$ structural fallback that strips the same 75-word stopword set $\mathcal{W}_{\text{stop}}$---comprising articles/determiners \{\texttt{a}, \texttt{an}, \texttt{the}, \texttt{this}, \texttt{that}, \texttt{these}, \texttt{those}, \texttt{any}, \texttt{each}, \texttt{every}, \texttt{some}, \texttt{such}\}, copulas/auxiliaries \{\texttt{is}, \texttt{are}, \texttt{was}, \texttt{were}, \texttt{be}, \texttt{been}, \texttt{being}, \texttt{can}, \texttt{could}, \texttt{may}, \texttt{might}, \texttt{will}, \texttt{would}, \texttt{should}, \texttt{do}, \texttt{does}, \texttt{did}, \texttt{has}, \texttt{have}, \texttt{had}\}, prepositions/conjunctions \{\texttt{to}, \texttt{of}, \texttt{from}, \texttt{as}, \texttt{at}, \texttt{into}, \texttt{about}, \texttt{through}, \texttt{during}, \texttt{including}, \texttt{whether}, \texttt{or}, \texttt{and}\}, and schema boilerplate verbs/nouns \{\texttt{used}, \texttt{using}, \texttt{use}, \texttt{specify}, \texttt{specifies}, \texttt{specifying}, \texttt{specified}, \texttt{represents}, \texttt{representing}, \texttt{indicates}, \texttt{indicating}, \texttt{denotes}, \texttt{denoting}, \texttt{defines}, \texttt{defining}, \texttt{provides}, \texttt{providing}, \texttt{contains}, \texttt{containing}, \texttt{parameter}, \texttt{field}, \texttt{value}, \texttt{property}, \texttt{attribute}, \texttt{object}, \texttt{string}, \texttt{number}, \texttt{optional}, \texttt{default}, \texttt{example}\}---and retains the first 7 alphanumeric content tokens preceding the first clause or preposition boundary \emph{plus} any late-occurring $\pm 2$-token content window surrounding a triggering digit, non-ASCII comparator [$\le, \ge, \neq$], or uppercase domain acronym occurring beyond the 7th content token):
\begin{enumerate}
    \item \textit{Format and Pattern Guard:} Retains descriptions matching anchored regex literals, length specifiers, or standard formats evaluated case-insensitively (\texttt{re.\allowbreak IGNORECASE}) with strict word-boundary and anchor guards (\texttt{r"((?:\textasciigrave|"|\textquotesingle)\textbackslash\string^|\allowbreak\textbackslash\$(?:\textasciigrave|"|\textquotesingle)|\allowbreak\textbackslash b(?:max|\allowbreak min)?\allowbreak len(?:gth)?\allowbreak\textbackslash s*[:=]?\allowbreak\textbackslash s*\textbackslash d+|\allowbreak\textbackslash b(?:regex|\allowbreak format|\allowbreak pattern|\allowbreak ISO-\textbackslash d+|\allowbreak RFC\textbackslash s*\textbackslash d+|\allowbreak UTC|\allowbreak GMT|\allowbreak epoch|\allowbreak uuid)\textbackslash b)"}, where requiring delimiter-adjacent \texttt{\textbackslash\string^} and \texttt{\textbackslash\$} with an ASCII grave accent \texttt{\textasciigrave}, double quote \texttt{"}, or single quote \texttt{\textquotesingle} prevents exponent expressions such as \texttt{10\string^6} or currency/environment literals such as \texttt{\$100} and \texttt{\$PATH} from falsely triggering the regex anchor branch).
    \item \textit{Numeric Bounds and Domain Units Guard:} Retains descriptions matching comparators, ranges, or domain/currency units with strict operand and word boundaries (compiled with \texttt{re.\allowbreak IGNORECASE} and an inline case-sensitive scope flag \texttt{(?-i:...)} on the uppercase \texttt{[A-Z]\{3\}} ISO-4217 currency code branch so common 3-letter words such as \texttt{"the code"} never match: \texttt{r"((?:>=|\allowbreak<=|\allowbreak!=|\allowbreak==|\allowbreak=|\allowbreak>|\allowbreak<)\textbackslash s*-?\textbackslash d+|\allowbreak\textbackslash bmin\textbackslash b|\allowbreak\textbackslash bmax\textbackslash b|\allowbreak\textbackslash bbetween\textbackslash b|\allowbreak\textbackslash brange\textbackslash b|\allowbreak\textbackslash d+\textbackslash s*(?:ms|\allowbreak s|\allowbreak MB|\allowbreak GB|\allowbreak USD|\allowbreak EUR|\allowbreak JPY|\allowbreak bps|\allowbreak cents|\allowbreak shares|\allowbreak lots|\allowbreak\%)\textbackslash b|\allowbreak(?-i:\textbackslash b[A-Z]\{3\}\textbackslash b)\textbackslash s+(?:currency|\allowbreak code))"}).
    \item \textit{Deontic and Polarity Guard:} Retains descriptions matching modal, negative, or ordering polarity markers case-insensitively with word boundaries (\texttt{\textbackslash b}: \texttt{not}, \texttt{never}, \texttt{must}, \texttt{required}, \texttt{disallow}, \texttt{prohibit}, \texttt{forbid}, \texttt{omit}, \texttt{exclude}, \texttt{only}, \texttt{strictly}, \texttt{ascending}, \texttt{descending}).
    \item \textit{Parameter Role Disambiguation Guard:} Whenever an object contains $\ge 2$ sibling parameters of identical primitive type or an abbreviated identifier ($\le 8$ characters or ending in a single-character suffix, e.g., \texttt{acct\_id\_a} vs.\ \texttt{acct\_id\_b}), the transpiler applies the same $\mathcal{O}(|d|)$ 75-stopword filter $\mathcal{W}_{\text{stop}}$ and retains up to 6 alphanumeric content tokens before halting at the first occurrence of the exhaustive 7-token boundary marker set \{\texttt{for}, \texttt{with}, \texttt{when}, \texttt{if}, \texttt{in}, \texttt{on}, \texttt{by}\} encountered \textit{after} at least 2 content tokens have been collected (so clause-initial prepositions such as \texttt{"For beneficiary settlement account..."} are skipped at index $0$ rather than halting extraction prematurely, and if two sibling parameters share an identical prefix before or across the preposition---e.g., \texttt{"Settlement account in domestic ledger"} vs.\ \texttt{"Settlement account in foreign ledger"}, or \texttt{"Settlement account in domestic ledger for originating bank"} vs.\ \texttt{"Settlement account in domestic ledger for beneficiary bank"}---extraction continues past the preposition up to 6 content tokens, or up to a hard ceiling of 10 content tokens when sibling descriptions have not yet diverged at token 6, until the first diverging content token and its immediate head noun are captured), preserving the disambiguating role qualifier (e.g., \texttt{"originating debit account"} vs.\ \texttt{"beneficiary settlement account"}).
\end{enumerate}

After description filtering, RFC 8259 whitespace minification \cite{bray2017rfc8259} is applied universally, and the bounded candidate family $\mathcal{S}_{\text{dense}}$ ($|\mathcal{S}_{\text{dense}}| = 2^3 = 8$) is parameterized by binary activation vector $\pi \in \{0, 1\}^3$ over three \textit{global document-level binary AST policies} evaluated in the fixed canonical transformation order $\text{(iii)} \to \text{(i)} \to \text{(ii)}$: (iii) verbose multi-branch union declarations (\texttt{\{"anyOf":\allowbreak[\{"type":\allowbreak"string"\},\allowbreak\{"type":\allowbreak"null"\}]\}} or OpenAPI 3.0 \texttt{\{"type":\allowbreak"string",\allowbreak"nullable":\allowbreak true\}}) vs.\ canonical JSON Schema Draft 2020-12 / OpenAPI 3.1 type-array literals (\texttt{\{"type":\allowbreak["string",\allowbreak"null"]\}}, applied \emph{if and only if} every \texttt{anyOf} branch consists solely of a pure \texttt{"type"} declaration without branch-specific keywords such as \texttt{"pattern"}, \texttt{"format"}, \texttt{"minimum"}, or \texttt{"enum"}, strictly preserving $S' \equiv_{\text{sem}} S$, and executed first so folded union keys participate uniformly in subsequent sorting and sub-tree hashing); (i) declaration order ($\pi_1=0$) vs.\ global lexicographical key sorting ($\pi_1=1$) across all object nodes (which sorts each object node's $d_v \le d_{\max}$ keys in $\mathcal{O}(\sum_v d_v \log d_v) = \mathcal{O}(|\mathcal{T}_{\text{AST}}| \log d_{\max})$ time, altering adjacent \texttt{\textquotesingle\{"\textquotesingle}, \texttt{\textquotesingle,"\textquotesingle}, \texttt{\textquotesingle":\textquotesingle}, \texttt{\textquotesingle",\textquotesingle}, and \texttt{\textquotesingle"\}\textquotesingle} delimiter-key transitions in $\mathcal{V}_M$); and (ii) inline sub-tree expansion vs.\ global bottom-up Merkle-hashed \texttt{\$defs}/\texttt{\$ref} type-alias hoisting (because policies execute in order $\text{(iii)} \to \text{(i)} \to \text{(ii)}$, sub-tree token length $L(\pi_1)$ and bottom-up Merkle hashes are evaluated per key-ordering branch $\pi_1 \in \{0, 1\}$; when active, identical post-pruning object sub-trees of token length $L(\pi_1) \ge 24$ repeating $r \ge 2$ times with strictly positive closed-form net token savings $\Delta\ell_{\text{hoist}}(L(\pi_1), r, d) = (r - 1)L(\pi_1) - (r\ell_{\text{ptr}}(d) + \ell_{\text{key}}(d) + \ell_{\text{wrap}}) > 0$---where pointer, alias-key, and wrapper costs are parameterized per target tokenizer $T_M$ via a one-time initialization lookup of $\ell_{\text{ptr}}(d) = |T_M(\texttt{\textquotesingle\{"\$ref":"\#/\$defs/T0"\}\textquotesingle})|$, $\ell_{\text{key}}(d) = |T_M(\texttt{\textquotesingle"T0":\textquotesingle})|$, and $\ell_{\text{wrap}} = |T_M(\texttt{\textquotesingle,"\$defs":\{\}\textquotesingle})|$, evaluating under both Gemini SentencePiece Unigram and \texttt{cl100k\_base} BPE to $\ell_{\text{ptr}}(1) = 11$, $\ell_{\text{key}}(1) \in \{3, 4\}$, and $\ell_{\text{wrap}} = 5$ for the first hoisted type initializing \texttt{"\$defs":\{\}} and $0$ for subsequent hoisted types [incrementing by $+1$ token to $\ell_{\text{ptr}}(2) = 12$ and $\ell_{\text{key}}(2) \in \{4, 5\}$ for two-digit alias indices $d = 2$ such as \texttt{"T10"}], evaluated jointly across all candidate sub-trees sharing the 5-token wrapper so $r=2$ hoists when $L(\pi_1) \ge 26\text{--}31$ tokens while $L(\pi_1)=24$ hoists when $r \ge 3$---are hoisted bottom-up into a shared top-level \texttt{"\$defs":\allowbreak\{"T0":...\}} container using fresh collision-safe alias identifiers \texttt{"T0"}, \texttt{"T1"} disjoint from any preexisting schema definitions). For long multi-token leaf strings and keys ($|v| \ge 4$ characters), no single SentencePiece Unigram or BPE subword token in $\mathcal{V}_M$ spans across the leaf interior and \textit{both} enclosing quotes simultaneously; specifically, let $b_{\text{sync}} \in \{2, \dots, \ell_{\text{qmax}}\}$ denote the character offset of the first unquoted interior subword synchronization boundary in $T_M$ (where $\ell_{\text{qmax}} \le 8$ bounds quote-merged tokens in $\mathcal{V}_M$, defaulting to $b_{\text{sync}} = 2$ after the 2-character delimiter prefix $\text{delim}_L \in \{\texttt{\textquotesingle\{"\textquotesingle}, \texttt{\textquotesingle,"\textquotesingle}\}$ to form the 4-character boundary window $\text{delim}_L \circ v[0:2]$). Rather than re-tokenizing unchanged leaf interiors 8 times from scratch, Stage 1 pre-tokenizes interior suffixes once in $\mathcal{O}(|S|)$ time, performs the one-time $\mathcal{O}(|\mathcal{T}_{\text{AST}}| \log d_{\max})$ lexicographical key sort and Merkle sub-tree hash pass, and evaluates a linear $\mathcal{O}(|\mathcal{T}_{\text{AST}}|)$ non-overlapping spliced boundary estimator around \texttt{\textquotesingle\{"\textquotesingle}, \texttt{\textquotesingle,"\textquotesingle}, \texttt{\textquotesingle":\textquotesingle}, \texttt{\textquotesingle",\textquotesingle}, and \texttt{\textquotesingle"\}\textquotesingle} via $\hat{\ell}_M(v, \text{delim}_L, \text{delim}_R) = |T_M(\text{delim}_L \circ v[0:b_{\text{sync}}])| + |T_M(v[b_{\text{sync}}:] \circ \texttt{\textquotesingle":\textquotesingle} \circ \text{delim}_R)|_{\text{cached}}$ for object keys (and $|T_M(\text{delim}_L \circ v[0:b_{\text{sync}}])| + |T_M(v[b_{\text{sync}}:-b_{\text{sync}}])|_{\text{cached}} + |T_M(v[-b_{\text{sync}}:] \circ \text{delim}_R)|$ for string values, while tokenizing short $\le 3$-character keys/literals with $|v| < 2 b_{\text{sync}}$ in full with their adjacent delimiters) so interior characters are never double-counted. Across all benchmark schemas ($N=1{,}000$ enterprise traces and $N=2{,}000$ BFCL schemas), this delta-estimator achieves a \textbf{99.85\% top-1 ranking agreement rate} with exhaustive 8-candidate full-sequence tokenization, and Stage 1 guarantees $100.0\%$ exact global optimum recovery by executing full-sequence tokenization $|T_M(S')|$ in Eq.~(\ref{eq:ast_min}) on the top-ranked candidate $\pi^*$ (plus the runner-up candidate whenever its estimated delta-count lies within $\le 2$ tokens of $\pi^*$, as well as any boundary-tied candidates):
\begin{equation}
\label{eq:dense_serialization}
S^* = \operatorname{SerializeDense}(\mathcal{T}_{\text{AST}}, \pi^*, \text{separators} = (\texttt{\textquotesingle,\textquotesingle}, \texttt{\textquotesingle:\textquotesingle}))
\end{equation}
in $< 0.8\text{ ms}$ on CPU with $0.00\%$ formal schema validation-contract or parameter-disambiguation loss.

\subsection{Information-Theoretic Invariant Density Compaction}
For an unstructured prompt instruction $I$, the compiler first scans each sentence for clause-initial negative polarity markers from $\mathcal{K}_{\text{inv}}$ sub-lexicon (ii) (defined below Eq.~\ref{eq:density_score}, e.g., \texttt{never}, \texttt{not}, \texttt{prohibit}, \texttt{cannot}) and records distributed negative polarity metadata ($\pi_{\text{inh}} = -$) across shared-subject coordinate verb phrases \textit{prior} to deterministic clause segmentation into $\mathcal{C} = \langle c_1, \dots, c_m \rangle$ (which splits on sentence-terminal punctuation, semicolons, markdown bullet/numbered list boundaries, and comma-preceded coordinating conjunctions in \{\texttt{and}, \texttt{or}, \texttt{nor}, \texttt{but}\}, and further segments clauses exceeding $L_{\text{clause}}^{\max} = 24$ subword tokens at subordinate conjunction markers \{\texttt{where}, \texttt{provided that}, \texttt{unless}, \texttt{such that}, \texttt{when}, \texttt{if}\}, or at coordinating conjunctions \{\texttt{and}, \texttt{or}, \texttt{nor}, \texttt{but}\} and 24-token whitespace boundaries outside protected SQL \texttt{BETWEEN X AND Y} ranges and \texttt{[attr, op, val]} predicate spans when no subordinate conjunction is present). Two deterministic syntactic rules prevent false polarity propagation across sub-clauses: (1) \textit{Antecedent conditional isolation:} any negation inside a leading subordinate conditional clause (\texttt{if ... ,}, \texttt{when ... ,}, \texttt{unless ... ,}, or \texttt{where ... ,}) is scoped strictly to the antecedent condition (terminating at the comma or main-clause deontic modal/verb boundary) and never propagates $\pi_{\text{inh}} = -$ into the consequent main clause (e.g., in \texttt{"If status is not \textquotesingle ACTIVE\textquotesingle, set retry\_count = 1"}, the main clause retains $\pi_{\text{inh}} = +$); and (2) \textit{Coordinate continuation vs.\ clause reset:} when a main clause opens with a negative auxiliary/adverb (\texttt{do not}, \texttt{never}, \texttt{cannot}, \texttt{must not}, \texttt{shall not}), inherited $\pi_{\text{inh}} = -$ persists strictly across unpunctuated coordinate verb phrases joined by bare \texttt{or}, \texttt{nor}, or \texttt{and} that elide both subject and modal auxiliary [e.g., \texttt{"Do not set role = \textquotesingle admin\textquotesingle\ or set status = \textquotesingle deleted\textquotesingle"}], automatically prepending a surface \texttt{"do not "} marker to the split continuation sub-clause so surface text in $\mathcal{I}_{\text{inv}}$ and signature polarity remain synchronized, whereas $\pi_{\text{inh}}$ resets to $+$ at semicolons, adversative \texttt{, but}/\texttt{but}, explicit positive deontic modals (\texttt{must}, \texttt{shall}, \texttt{should}, \texttt{always}, \texttt{ensure}), or comma-delimited independent imperative clauses \texttt{, and <verb>} [e.g., \texttt{"Never delete audit logs, and set status = \textquotesingle ARCHIVED\textquotesingle"}, unless \texttt{, and} is immediately followed by a negative marker or \texttt{neither}/\texttt{nor}], while joint conjunctive prohibitions matching \texttt{not both A and B} are retained intact as a single compound constraint rather than split.

To prevent conversational pleasantries or previously seen predicate signatures from causing a compound clause's novel modal constraints to be dropped, Stage 2 executes \textit{sub-clause span stripping} in $< 0.4\text{ ms}$ via a pre-compiled Aho-Corasick automaton:
\begin{enumerate}
    \item Input clauses undergo lowercase folding and whitespace normalization (collapsing contiguous whitespace to single spaces while preserving original character offsets) prior to matching against $\operatorname{IsPadding}$---comprising the exact 18 polite/persona templates (\texttt{"please kindly"}, \texttt{"thank you in advance"}, \texttt{"as a helpful ai assistant"}, \texttt{"i would like you to"}, \texttt{"could you please"}, \texttt{"make sure to carefully"}, \texttt{"i really appreciate your help"}, \texttt{"if it is not too much trouble"}, \texttt{"you are an expert world-class"}, \texttt{"take a deep breath and"}, \texttt{"think step by step and"}, \texttt{"hope you are doing well"}, \texttt{"please be so kind as to"}, \texttt{"it is very important that you"}, \texttt{"for a \$200 tip please"}, \texttt{"hello there assistant"}, \texttt{"thank you so much for"}, and \texttt{"we kindly request that you"})---which strips matched boilerplate spans at the substring level rather than rejecting the enclosing clause.
    \item A deterministic slot-grammar extractor normalizes \texttt{camelCase}/\texttt{snake\_case} schema identifiers from $\mathcal{T}_{\text{AST}}(S)$ into lowercase token stems (falling back, when no external schema $S$ is provided, to the 75-stopword filter $\mathcal{W}_{\text{stop}}$ by extracting up to 3 contiguous alphanumeric content tokens immediately preceding the relational operator as a compound noun-phrase stem, e.g., \texttt{source\_balance} vs.\ \texttt{target\_balance}, preventing single-token stem collisions) and binds them to relational operators $\texttt{op} \in \mathcal{S}_{\text{sym}}$, right-hand literal values $\texttt{val}$ (extracted via a deterministic token-window production grammar matching a quoted string literal, numeric/currency literal, boolean/null keyword, parenthesized \texttt{IN (...)} tuple up to the closing \texttt{)}, or \texttt{BETWEEN val1 AND val2} range), normalized conditional/entity scope qualifier $\texttt{scope}$ (where any enclosing condition introduced by \texttt{when}, \texttt{if}, \texttt{where}, or \texttt{unless}---terminated at a comma, semicolon, sentence boundary, or main-clause deontic modal---or trailing \texttt{for <entity>} target---terminated at the next punctuation mark, conjunction, or after at most 4 non-stopword content tokens---is lowercase-folded, stripped of $\mathcal{W}_{\text{stop}}$, and canonicalized into a prefix-tagged token string by mapping \texttt{unless <cond>} to \texttt{if\_not:<tokens>}, \texttt{when}/\texttt{if}/\texttt{where <cond>} to \texttt{if:<tokens>} with relational comparators normalized and tokens joined by \texttt{\_}, and \texttt{for <entity>} to \texttt{for:<tokens>} [so both \texttt{"when the user is admin"} and \texttt{"if user = admin"} canonicalize to \texttt{if:user\_=\_admin}, whereas \texttt{"unless user is admin"} canonicalizes to \texttt{if\_not:user\_=\_admin}], defaulting to $\texttt{global}$ when unconditional so identical assignments under distinct conditions or entity scopes never collide), and effective polarity $\pi \in \{+, -\}$ (merging pre-segmentation inherited clause-initial auxiliary polarity $\pi_{\text{inh}} = -$ idempotently with that same clause-initial auxiliary token if still inside the local 5-token pre-operator window so a clause-initial \texttt{"Never"} is never counted twice, whereas when a negative auxiliary/adverb [\texttt{not}, \texttt{never}, \texttt{cannot}, \texttt{without}] co-occurs with a distinct negative action verb [\texttt{omit}, \texttt{exclude}, \texttt{disallow}, \texttt{forbid}, \texttt{prohibit}, \texttt{reject}, \texttt{deny}, \texttt{prevent}] inside the pre-operator window---e.g., \texttt{"do not exclude role = \textquotesingle admin\textquotesingle"} or \texttt{"must never omit status = \textquotesingle ACTIVE\textquotesingle"}---their distinct syntactic roles combine multiplicatively as $\pi = (-1) \times (-1) = +$, and genuine double negations where $\pi = -$ co-occurs with a negative operator \texttt{!=}, \texttt{<>}, \texttt{NOT IN}, or \texttt{NOT LIKE} canonicalize into $(\pi = +, \texttt{=})$, $(\pi = +, \texttt{IN})$, or $(\pi = +, \texttt{LIKE})$) to extract canonical 5-tuples $\operatorname{Sig}(\tilde{c}_k) = \{\texttt{(attr, }\pi\texttt{, op, val, scope)}\} \subseteq \mathcal{U}_{\text{inv}}$ (ensuring opposing statements such as \texttt{"must set role = \textquotesingle admin\textquotesingle"} [$\pi=+$] and \texttt{"must never set role = \textquotesingle admin\textquotesingle"} [$\pi=-$] produce distinct signatures).
    \item Let $\mathcal{S}_{\text{seen}}(k) \triangleq \bigcup_{j < k : \operatorname{Retain}(c_j)} \operatorname{Sig}(\tilde{c}_j)$ [with base case $k = 1$, where $\mathcal{S}_{\text{seen}}(1) = \emptyset$] denote the set of already-retained signatures, and let $\operatorname{Sig}_{\text{new}}(\tilde{c}_k) \triangleq \operatorname{Sig}(\tilde{c}_k) \setminus \mathcal{S}_{\text{seen}}(k)$. Each extracted tuple records its full local verb/determiner plus \texttt{[attr, op, val]} surface phrase span so that excising any duplicate signature span $\operatorname{Sig}(\tilde{c}_k) \cap \mathcal{S}_{\text{seen}}(k)$ preserves shared clause-initial deontic/negative modals (e.g., \texttt{"must never set"}), trims any adjacent dangling coordinating conjunction (\texttt{or}, \texttt{nor}, \texttt{and}, \texttt{\textquotesingle,\textquotesingle}; promoting \texttt{nor} to \texttt{and never} if the first conjunct is excised and no shared clause-initial negative modal is already preserved ahead of the conjunction, or trimming \texttt{nor} otherwise to prevent double negation), and cleanly re-stitches \texttt{"must never set role = \textquotesingle admin\textquotesingle\ or status = \textquotesingle deleted\textquotesingle"} into the residual sub-clause $\tilde{c}_k =$ \texttt{"must never set status = \textquotesingle deleted\textquotesingle"} (with $\operatorname{Sig}(\tilde{c}_k) = \operatorname{Sig}_{\text{new}}(\tilde{c}_k)$, which is $\emptyset$ when Disjunct 1 of Eq.~(\ref{eq:retention_filter}) is false; when $\operatorname{Retain}(c_k)$ holds, the span-stripped residual clause $\tilde{c}_k$ is emitted into $\mathcal{I}_{\text{inv}}$).
\end{enumerate}

We evaluate the empirical invariant density score $\mathcal{D}_{\text{inv}}(\tilde{c}_k)$ on the residual sub-clause $\tilde{c}_k$:
\begin{equation}
\label{eq:density_score}
\mathcal{D}_{\text{inv}}(\tilde{c}_k) \triangleq \frac{2.0 \cdot \operatorname{Count}(\tilde{c}_k, \mathcal{K}_{\text{inv}}) + 1.0 \cdot \operatorname{Count}(\tilde{c}_k, \mathcal{S}_{\text{sym}})}{|T_M(\tilde{c}_k)| + 1}
\end{equation}
where $\mathcal{K}_{\text{inv}}$ ($|\mathcal{K}_{\text{inv}}| = 64$, extensible with user-registered custom domain lexicons at initialization) comprises four 16-token deterministic sub-lexicons matched case-insensitively: (i) deontic modals (\texttt{must}, \texttt{shall}, \texttt{required}, \texttt{mandatory}, \texttt{enforce}, \texttt{ensure}, \texttt{always}, \texttt{strictly}, \texttt{only}, \texttt{exact}, \texttt{bound}, \texttt{limit}, \texttt{verify}, \texttt{assert}, \texttt{guarantee}, \texttt{comply}), (ii) negative polarity markers (\texttt{never}, \texttt{not}, \texttt{cannot}, \texttt{prohibit}, \texttt{exclude}, \texttt{disallow}, \texttt{forbid}, \texttt{omit}, \texttt{reject}, \texttt{deny}, \texttt{prevent}, \texttt{without}, \texttt{none}, \texttt{neither}, \texttt{invalid}, \texttt{illegal}), (iii) relational/SQL keywords (\texttt{select}, \texttt{where}, \texttt{join}, \texttt{group}, \texttt{having}, \texttt{order}, \texttt{distinct}, \texttt{from}, \texttt{union}, \texttt{intersect}, \texttt{exists}, \texttt{between}, \texttt{asc}, \texttt{desc}, \texttt{ascend}, \texttt{descend}), and (iv) schema/domain contract specifiers (\texttt{type}, \texttt{enum}, \texttt{format}, \texttt{nullable}, \texttt{unique}, \texttt{primary}, \texttt{foreign}, \texttt{index}, \texttt{schema}, \texttt{pattern}, \texttt{minimum}, \texttt{maximum}, \texttt{integer}, \texttt{boolean}, \texttt{string}, \texttt{utc}); and $\mathcal{S}_{\text{sym}}$ ($|\mathcal{S}_{\text{sym}}| = 29$) comprises relational, mathematical, and structural operators (\texttt{=}, \texttt{==}, \texttt{!=}, \texttt{<>}, \texttt{<}, \texttt{>}, \texttt{<=}, \texttt{>=}, \texttt{IN}, \texttt{NOT IN}, \texttt{LIKE}, \texttt{NOT LIKE}, \texttt{IS NULL}, \texttt{NOT NULL}, \texttt{::}, \texttt{->}, \texttt{=>}, \texttt{+}, \texttt{-}, \texttt{*}, \texttt{/}, \texttt{\%}, \texttt{\&\&}, \texttt{||}, \texttt{!}, \texttt{\textquotesingle\{\textquotesingle}, \texttt{\textquotesingle\}\textquotesingle}, \texttt{\textquotesingle[\textquotesingle}, \texttt{\textquotesingle]\textquotesingle}), where $\operatorname{Count}(\tilde{c}_k, \mathcal{S}_{\text{sym}})$ enforces longest-match-first non-overlapping operator tokenization (so \texttt{<=}, \texttt{!=}, \texttt{==}, \texttt{NOT IN}, \texttt{NOT LIKE}, and \texttt{NOT NULL} are matched as single operators rather than decomposed into constituent symbols) with strict case-sensitive word-boundary guards (\texttt{\textbackslash b}) on the uppercase SQL operators (\texttt{IN}, \texttt{NOT IN}, \texttt{LIKE}, \texttt{NOT LIKE}, \texttt{IS NULL}, \texttt{NOT NULL}), and strips matched multi-word SQL operator spans prior to evaluating $\operatorname{Count}(\tilde{c}_k, \mathcal{K}_{\text{inv}})$ so \texttt{NOT} inside \texttt{NOT IN}/\texttt{NOT LIKE}/\texttt{NOT NULL} is not double-counted across both lexicons.

To eliminate denominator-growth pruning on long clauses and replace legacy fixed-window thresholds ($|T_M(\tilde{c}_k)| \le 12$), the retention filter combines inverse-length threshold scaling in Disjunct 3 with an ultra-short single-operator condition in Disjunct 2:
\begin{align}
\label{eq:retention_filter}
\operatorname{Retain}(c_k) &\iff \Big( \operatorname{Sig}_{\text{new}}(\tilde{c}_k) \neq \emptyset \Big) \nonumber \\
&\lor \Big( |\operatorname{T}_M(\tilde{c}_k)| \le 2 \land \mathcal{D}_{\text{inv}}(\tilde{c}_k) \ge \tau_{\text{info}} \Big) \nonumber \\
&\lor \Big( |\operatorname{T}_M(\tilde{c}_k)| \ge 1 \land \mathcal{D}_{\text{inv}}(\tilde{c}_k) \ge \frac{w_{\min}}{|\operatorname{T}_M(\tilde{c}_k)| + 1} \Big)
\end{align}
where $\tau_{\text{info}} = 0.30$ and $w_{\min} \triangleq \min(2.0,\, \min_{t \in \texttt{custom\_lexicon}} w_{\text{cust}}(t))$ denotes the minimum lexical invariant weight across $\mathcal{K}_{\text{inv}}$ and any user-registered \texttt{custom\_lexicon} extensions (so when fractional custom weights $w_{\text{cust}} \in (0, 2.0)$ are registered, Disjunct 3 scales its numerator constant to $w_{\min}$ and retains any clause with weighted numerator $W(\tilde{c}_k) \ge w_{\min}$ regardless of length). Under the default integer weights $(2.0, 1.0)$ where $w_{\min} = 2.0$, the weighted numerator $W(\tilde{c}_k) \triangleq 2.0 \cdot \operatorname{Count}(\tilde{c}_k, \mathcal{K}_{\text{inv}}) + 1.0 \cdot \operatorname{Count}(\tilde{c}_k, \mathcal{S}_{\text{sym}}) \in \{0, 1, 2, \dots\}$ reduces Disjuncts 2 and 3 algebraically to $(|T_M(\tilde{c}_k)| \in \{1, 2\} \land W(\tilde{c}_k) \ge 1) \lor (|T_M(\tilde{c}_k)| \ge 1 \land W(\tilde{c}_k) \ge 2)$: any residual clause with $W(\tilde{c}_k) \ge 2$ ($\operatorname{Count}(\tilde{c}_k, \mathcal{K}_{\text{inv}}) \ge 1$ or $\operatorname{Count}(\tilde{c}_k, \mathcal{S}_{\text{sym}}) \ge 2$) is \textit{unconditionally retained} via Disjunct 3 regardless of clause length, Disjunct 2 uniquely captures ultra-short single-operator fragments ($W(\tilde{c}_k) = 1, |T_M(\tilde{c}_k)| \in \{1, 2\}$), and Disjunct 1 uniquely triggers when $W(\tilde{c}_k) = 1$ and $|T_M(\tilde{c}_k)| \ge 3$ (retaining unmodalized single-operator relational clauses such as \texttt{"set account\_status = \textquotesingle ACTIVE\textquotesingle\ for all qualifying rows"} whenever $\operatorname{Sig}_{\text{new}}(\tilde{c}_k) \neq \emptyset$; conversely, purely prose-based imperative clauses that lack symbolic operators in $\mathcal{S}_{\text{sym}}$, deontic modals in $\mathcal{K}_{\text{inv}}$, and negative markers---and instead use unmodalized action verbs outside the 64-token default lexicon such as bare \texttt{"skip archived records"} or \texttt{"ignore test accounts"}---require registering those domain verbs in \texttt{custom\_lexicon}). We note an intentional precision-recall design trade-off in Disjunct 3: because $\mathcal{K}_{\text{inv}}$ includes polysemous words (\texttt{from}, \texttt{only}, \texttt{type}, \texttt{order}, \texttt{limit}) that also occur in general prose, Stage 2 deliberately prioritizes $100\%$ constraint recall across all $\mathcal{K}_{\text{inv}} \cup \mathcal{S}_{\text{sym}}$ (and registered \texttt{custom\_lexicon}) constraints (zero false-negative drops) over maximal compression, accepting a measured $4.8\%$ false-positive conversational clause retention rate across the 1,000-trace benchmark as a conservative safety margin.

\subsection{Transformer Attention Entropy Bounding via Landmark Sinks under RoPE}
To eliminate attention dispersion across large context windows, the compiler injects a $K=7$-token uppercase structural landmark header (\texttt{\#\#\# MANDATORY EXECUTION INVARIANTS:}) immediately preceding the retained Stage 2 invariant clauses (replacing any preexisting informal section labels such as \texttt{Rules:} or \texttt{Constraints:}, which average $4.5\text{ tokens}$ across enterprise traces, for a net addition of $+7.0 - 4.5 = +2.5\text{ tokens}$). Modern Transformer architectures implement Rotary Position Embeddings (RoPE) \cite{su2024roformer}, rotating real query and key vectors $\mathbf{q}_m = \mathbf{W}_Q \mathbf{x}_m \in \mathbb{R}^d$ and $\mathbf{k}_n = \mathbf{W}_K \mathbf{x}_n \in \mathbb{R}^d$ of dimension $d \equiv d_{\text{head}}$ at token position $m$ via the block-diagonal orthogonal matrix:
\begin{align}
\mathbf{R}_{\Theta, m}^d &= \operatorname{diag}\left(\mathbf{R}_{\theta_1, m}, \dots, \mathbf{R}_{\theta_{d/2}, m}\right), \label{eq:rope_matrix} \\
\mathbf{R}_{\theta_r, m} &= \begin{pmatrix} \cos(m\theta_r) & -\sin(m\theta_r) \\ \sin(m\theta_r) & \cos(m\theta_r) \end{pmatrix} \label{eq:rope_2d}
\end{align}
with base parameter $b = 10{,}000$ and frequency $\theta_r = b^{-2(r-1)/d}$ for $r \in \{1, \dots, d/2\}$. Defining the complexified 2D coordinate pair $(\mathbf{v})_r \triangleq v_{2r-1} + \mathrm{i}\,v_{2r} \in \mathbb{C}$ where upright $\mathrm{i} = \sqrt{-1}$ denotes the imaginary unit (distinct from italic query index $i$) and $(\cdot)^*$ denotes complex conjugation (distinct from the optimality superscript $*$ in $S^*$ and $T_{\text{think}}^*$), the RoPE-rotated inner product between $\tilde{\mathbf{q}}_m = \mathbf{R}_{\Theta, m}^d \mathbf{q}_m$ and $\tilde{\mathbf{k}}_n = \mathbf{R}_{\Theta, n}^d \mathbf{k}_n$ decomposes over relative token distance $(m - n)$:
\begin{equation}
\label{eq:rope_inner_prod}
\begin{aligned}
\langle \mathbf{R}_{\Theta, m}^d \mathbf{q}_m,\, \mathbf{R}_{\Theta, n}^d \mathbf{k}_n \rangle &= \\
\operatorname{Re}\!\Bigg( \sum_{r=1}^{d/2} &(\mathbf{W}_Q \mathbf{x}_m)_r (\mathbf{W}_K \mathbf{x}_n)_r^* e^{\mathrm{i}(m-n)\theta_r} \Bigg)
\end{aligned}
\end{equation}

Prior to stating Theorem 1, we explicitly distinguish between the two complementary physical mechanisms operating across heterogeneous Transformer attention heads: (1) on \textit{dispersive background heads}, the $K=7$ structural landmark header tokens $\mathcal{S}_i$ act as high-capacity attention sinks \cite{xiao2023streamingllm} that absorb residual attention mass from noisy background tokens $\mathcal{O}_i = \{1, \dots, i\} \setminus \mathcal{S}_i$, which is the mechanism bounded analytically by Theorem 1; and (2) on \textit{induction and retrieval heads} \cite{vaswani2017attention}, physically co-locating the Stage 2 invariant predicate tokens $\mathcal{I}_i \subset \mathcal{O}_i$ immediately beneath $\mathcal{S}_i$ enables direct semantic retrieval amplification (discussed below Theorem 1). For a given query token $i$ and antecedent key $j \le i$ at an individual attention head, let $z_{ij} \triangleq \langle \tilde{\mathbf{q}}_i, \tilde{\mathbf{k}}_j \rangle / \sqrt{d_{\text{head}}}$ denote the pre-softmax attention logit (or $z_{ij} \triangleq \text{cap} \cdot \tanh(\langle \tilde{\mathbf{q}}_i, \tilde{\mathbf{k}}_j \rangle / (\text{cap}\sqrt{d_{\text{head}}}))$ on logit-soft-capped architectures such as Gemma-2-9B \cite{gemma2_2024}), let $w_j \triangleq \exp(z_{ij})$ denote the unnormalized softmax weight such that $A_{ij} = w_j / \sum_{m=1}^i w_m$, and let $\Delta_{so} \triangleq z_{is} - z_{io} = \ln(w_s / w_o)$ denote the pairwise logit margin between landmark token $s \in \mathcal{S}_i$ and background token $o \in \mathcal{O}_i$.

\begin{theorem}[Information-Theoretic Attention Entropy Bounding on Dispersive Heads]
\label{thm:entropy_bound}
Let a context sequence contain $N$ tokens, among which for any query position $i > |\mathcal{P}_{\text{prefix}}| + \Delta_{\text{frag}} + K$ an active antecedent subset $\mathcal{S}_i = \mathcal{S} \subset \{1, \dots, i-1\}$ of $K = |\mathcal{S}_i|$ tokens ($0 < K < i \le N$) are designated as structural landmark anchors exhibiting either a pointwise unnormalized attention weight ratio $\min_{s \in \mathcal{S}_i} w_s / \max_{o \in \mathcal{O}_i} w_o \ge \gamma > 1$ (equivalent to a worst-case pointwise logit margin $\min_{s \in \mathcal{S}_i, o \in \mathcal{O}_i} \Delta_{so} \ge \ln\gamma$ over non-header indices $\mathcal{O}_i = \{1, \dots, i\} \setminus \mathcal{S}_i$) or, more generally, a group-mean unnormalized weight ratio $\frac{\frac{1}{K}\sum_{s \in \mathcal{S}_i} w_s}{\frac{1}{i - K}\sum_{o \in \mathcal{O}_i} w_o} = \frac{P_{\mathcal{S}}/K}{(1 - P_{\mathcal{S}})/(i - K)} \ge \gamma > 1$ where $P_{\mathcal{S}} = \sum_{s \in \mathcal{S}_i} A_{is}$. Under causal masking, the Shannon entropy of the query attention distribution $\mathbf{a}_i$ for any query token $i > K$ at an individual self-attention head is strictly bounded by:
\begin{equation}
\label{eq:entropy_bound}
\mathcal{H}(\mathbf{a}_i) \le \mathcal{H}_{\max}(i, K, \gamma) < \ln i
\end{equation}
where $\mathcal{H}_{\max}(i, K, \gamma) = \ln(i + K(\gamma - 1)) - \frac{K\gamma \ln\gamma}{i + K(\gamma - 1)}$, and the supremum $\mathcal{H}_{\max}$ is strictly monotonically decreasing in $\gamma$ for all $\gamma > 1$.
\end{theorem}

\begin{IEEEproof}
Because Shannon entropy is strictly Schur-concave on the probability simplex $\Delta^{i-1}$, for any fixed total probability mass $P_{\mathcal{S}} = \sum_{s \in \mathcal{S}_i} A_{is}$ allocated to the $K$ landmark tokens, conditional entropy is uniquely maximized by intra-group uniformity within both the landmark subset $\mathcal{S}_i$ (with uniform per-token probability $p_s = P_{\mathcal{S}}/K$) and the complement subset $\mathcal{O}_i$ (with uniform per-token probability $p_o = (1 - P_{\mathcal{S}})/(i - K)$). Note that the pointwise dominance condition $\min_{s \in \mathcal{S}_i} w_s \ge \gamma \max_{o \in \mathcal{O}_i} w_o$ directly implies the group-mean weight ratio $\frac{P_{\mathcal{S}}/K}{(1 - P_{\mathcal{S}})/(i - K)} \ge \gamma$, equivalent to $P_{\mathcal{S}} \ge \frac{K\gamma}{K\gamma + (i - K)}$. Under intra-group uniformity, the two-group entropy is:
\begin{equation}
h(P_{\mathcal{S}}) = - P_{\mathcal{S}} \ln\left(\frac{P_{\mathcal{S}}}{K}\right) - (1 - P_{\mathcal{S}}) \ln\left(\frac{1 - P_{\mathcal{S}}}{i - K}\right)
\end{equation}
Differentiating with respect to $P_{\mathcal{S}}$ yields:
\begin{equation}
\frac{dh}{dP_{\mathcal{S}}} = \ln\left( \frac{1 - P_{\mathcal{S}}}{P_{\mathcal{S}}} \cdot \frac{K}{i - K} \right) = \ln\left(\frac{p_o}{p_s}\right)
\end{equation}
Because $p_s / p_o \ge \gamma > 1$, we have $\ln(p_o / p_s) \le -\ln\gamma < 0$. Thus, $h(P_{\mathcal{S}})$ is strictly decreasing in $P_{\mathcal{S}}$ on $\left[\frac{K\gamma}{K\gamma + (i-K)}, 1\right)$, establishing that the global entropy supremum occurs at the lower boundary $p_s / p_o = \gamma$, where all $K$ landmark tokens share uniform weight $w_s = \gamma$ and all $i - K$ complement tokens share baseline weight $w_o = 1.0$. The partition function is:
\begin{equation}
\label{eq:partition_z}
Z_i = K\gamma + (i - K)
\end{equation}
The probability allocated to each landmark sink is $p_s = \gamma/Z_i$, while each remaining token receives $p_o = 1/Z_i$. The Shannon entropy evaluates to:
\begin{equation}
\label{eq:entropy_derivation}
\mathcal{H}_{\max}(i, K, \gamma) = \ln Z_i - \frac{K\gamma \ln\gamma}{Z_i}
\end{equation}
Differentiating $\mathcal{H}_{\max}$ with respect to $\gamma$, and noting that $\frac{\partial Z_i}{\partial\gamma} = K$:
\begin{equation}
\label{eq:term1_deriv}
\frac{\partial}{\partial\gamma}[\ln Z_i] = \frac{1}{Z_i}\frac{\partial Z_i}{\partial\gamma} = \frac{K}{Z_i} = \frac{K Z_i}{Z_i^2}
\end{equation}
\begin{equation}
\label{eq:term2_deriv}
\frac{\partial}{\partial\gamma}\left[\frac{K\gamma\ln\gamma}{Z_i}\right] = \frac{K Z_i + K(i - K)\ln\gamma}{Z_i^2}
\end{equation}
Subtracting the two derivatives:
\begin{equation}
\label{eq:strict_neg_deriv}
\frac{\partial\mathcal{H}_{\max}}{\partial\gamma} = -\frac{K(i - K)\ln\gamma}{Z_i^2} < 0 \quad \forall \gamma > 1
\end{equation}
This concludes the proof.
\end{IEEEproof}

\textbf{Two-Group Sink Absorption vs.\ Three-Group Constraint Co-Location:} Under Theorem 1's two-group partition ($\mathcal{S}_i$ vs.\ $\mathcal{O}_i$), all retained Stage 2 semantic constraint predicate tokens $\mathcal{I}_i \subset \mathcal{O}_i$ reside inside the non-header complement $\mathcal{O}_i$. On dispersive background heads where header sink dominance $\gamma > 1$ holds, the $K=7$ header tokens absorb $P_{\mathcal{S}} \ge \frac{K\gamma}{K\gamma + (i-K)}$ of total attention probability (at $\bar{N}=466.7, K=7, \gamma=100$, $\mathcal{S}_i$ absorbs $60.36\%$ of attention weight under the two-group uniform-complement baseline, leaving $1 - P_{\mathcal{S}} = 39.64\%$ across $\mathcal{O}_i$), suppressing uniform background dispersion. Conversely, partitioning the simplex into three disjoint groups---header sinks $\mathcal{S}_i$ ($K$ tokens, group-mean weight ratio $\gamma_{\mathcal{S}} = \bar{w}_{\mathcal{S}}/\bar{w}_{\mathcal{B}}$, mass $P_{\mathcal{S}}$), co-located invariant predicates $\mathcal{I}_i$ ($M_{\text{inv}}$ tokens, group-mean weight ratio $\gamma_{\mathcal{I}} = \bar{w}_{\mathcal{I}}/\bar{w}_{\mathcal{B}}$, mass $P_{\mathcal{I}}$), and noisy background context $\mathcal{B}_i = \mathcal{O}_i \setminus \mathcal{I}_i$ ($i - K - M_{\text{inv}}$ tokens, unit baseline weight, mass $P_{\mathcal{B}} = 1 - P_{\mathcal{S}} - P_{\mathcal{I}}$)---yields the exact invariant attention share:
\begin{equation}
\label{eq:three_group_partition}
\begin{split}
P_{\mathcal{I}}(\text{anchored}) &= M_{\text{inv}}\,\gamma_{\mathcal{I}}(\text{anchored}) \\
&\quad \Big/ \big( K\gamma_{\mathcal{S}} + M_{\text{inv}}\,\gamma_{\mathcal{I}}(\text{anchored}) \\
&\qquad + (i - K - M_{\text{inv}}) \big)
\end{split}
\end{equation}
This three-group partition captures the distinct operational regimes of dispersive versus \textit{induction and retrieval heads} \cite{vaswani2017attention}. Empirically on Gemma-2-9B at $\bar{N}=466.7$ ($M_{\text{inv}}=28$), the $78.6\%$ dispersive heads exhibit $(\gamma_{\mathcal{S}}, \gamma_{\mathcal{I}}) = (100.0, 1.8)$ (parking $P_{\mathcal{S}} = 700 / (700 + 28(1.8) + 431.7) = 59.22\% \approx 59.0\%$ on the header sink---shifting slightly from the two-group $60.36\%$ due to $\gamma_{\mathcal{I}}=1.8 > 1$ on $\mathcal{I}_i$---to prevent background dispersion), whereas the remaining $21.4\%$ retrieval/induction heads are not governed by Theorem 1's $\gamma_{\mathcal{S}} \gg 1$ premise ($\gamma_{\mathcal{S}} = 3.2$, adding only $K(\gamma_{\mathcal{S}} - 1) = 15.4$ to the partition denominator). Instead, physically co-locating all retained Stage 2 invariant clauses into a contiguous span immediately beneath the landmark header $\mathcal{S}_i$ acts as an induction-head positional beacon that boosts $\gamma_{\mathcal{I}}$ on retrieval heads from $4.1$ (unanchored, $K=0, P_{\mathcal{I}} = 0.207$) to $14.6$ (single-pass anchored, $P_{\mathcal{I}} = 0.474$) and up to $21.6$ on multi-clause induction heads ($P_{\mathcal{I}} = 0.571$, a $2.29\times$ to $2.76\times$ plug-in ratio at $\bar{N}=466.7$ [$0.571/0.207 = 2.76\times$], and a $2.80\times$ empirical trace-averaged amplification ratio across all multi-clause induction heads).

\textbf{Empirical Validation Across Model Families and Layer Aggregation:} While Eq.~(\ref{eq:rope_inner_prod}) exhibits oscillatory phase rotation across high-frequency RoPE subspaces ($r \ll d/2$), sustaining $\Delta_{so} \ge 4.60$ across downstream query positions relies jointly on two empirical properties of uppercase markdown delimiter tokens (\texttt{\#\#\#\allowbreak\ MANDATORY\allowbreak\ EXECUTION\allowbreak\ INVARIANTS:}) in low-frequency RoPE subspaces ($r \to d/2$, where $\theta_r \ll 1$ undergoes negligible phase rotation over relative token distances $i - s \le 450$): (i) large key-projection norms $\|\mathbf{W}_K \mathbf{x}_s\|_2$, and (ii) consistent positive query-key directional alignment $\operatorname{Re}\!\left((\mathbf{W}_Q \mathbf{x}_i)_r (\mathbf{W}_K \mathbf{x}_s)_r^*\right) > 0$ (empirically, the low-frequency subspace phase angle satisfies $\arg\!\left((\mathbf{W}_Q \mathbf{x}_i)_r (\mathbf{W}_K \mathbf{x}_s)_r^*\right) \in [-0.38, +0.41]\text{ rad} \subset (-\pi/2, \pi/2)$ across $96.4\%$ of query tokens on dispersive heads). Because commercial closed APIs do not expose internal attention matrices, we measured this affinity margin directly on open-weights Gemma-2-9B \cite{gemma2_2024} (SentencePiece Unigram) deployed on Cloud TPU v6e Trillium across its 21 global full-attention and 21 alternating sliding-window local-attention layers (where $\Delta_{so} \ge 4.60$ is measured directly on post-cap logits $z_{ij}$ under $\text{cap} = 50.0$; pre-cap scaled inner products $\langle \tilde{\mathbf{q}}_i, \tilde{\mathbf{k}}_j \rangle / \sqrt{d_{\text{head}}} \in [-3.2, 14.8]$ experience at most $14.8 - 50\tanh(14.8/50) = 0.41$ logit units of soft-cap compression, and alternative 7-token uppercase markdown delimiters such as \texttt{\#\#\#\allowbreak\ CRITICAL\allowbreak\ SYSTEM\allowbreak\ CONSTRAINTS:} and \texttt{===\allowbreak\ REQUIRED\allowbreak\ INVARIANT\allowbreak\ RULES:} similarly sustain $\ln\gamma \in [4.48, 5.06]$). To verify generalization beyond SentencePiece Unigram and soft-capped architectures, we replicated white-box attention telemetry on BPE-tokenized Llama-3.1-8B-Instruct (32 full-attention layers without logit soft-capping), confirming $\ln\gamma \in [4.42, 4.95]$ ($\gamma \in [83.1, 141.2]$, head-mean $\bar{\gamma} = 93.3$) across dispersive heads and empirical entropy $\mathcal{H}_{\text{empirical}} = 4.26\text{ nats} \le \mathcal{H}_{\max}(466.7, 7, \bar{\gamma}=93.3) = 4.35\text{ nats} < \mathcal{H}_{\max}(466.7, 7, 83.1) = 4.48\text{ nats}$ (and $\mathcal{H}_{\max}(466.7, 8, 83.1) = 4.41\text{ nats}$ when including \texttt{<bos>}, vs.\ $6.09\text{ nats}$ unanchored). To avoid confounding sequence-initial sink effects \cite{xiao2023streamingllm} or Jensen's inequality distortion on Gemma-2-9B, we denote $\mathcal{O}_i' = \mathcal{O}_i \setminus \{1\}$; because $\frac{\partial \mathcal{H}_{\max}(i, K, \gamma)}{\partial K} = \frac{(\gamma - 1)Z_i - i\gamma\ln\gamma}{Z_i^2} < 0 \iff i > \frac{(\gamma - 1)^2}{\gamma\ln\gamma - (\gamma - 1)}K \approx 189.8$ at $K=7, \gamma=100$, treating \texttt{<bos>} ($j=1$, which satisfies $w_1 \ge \gamma \bar{w}_{\mathcal{O}_i'}$) as an 8th sink with conservative uniform weight $\gamma = 100$ strictly tightens Theorem 1's upper bound across the entire benchmark domain $i \in [190, 2{,}000]$, reducing $\mathcal{H}_{\max}(466.7, K, 100)$ from $4.28\text{ nats}$ at $K=7$ to $4.21\text{ nats}$ at $K=8$ (and to $4.07\text{ nats}$ when incorporating the higher empirical \texttt{<bos>} weight $\gamma_1 \approx 245$ corresponding to $A_{i1} = 0.082$). Across relative distances $i - s \in [1, 450]$, the per-head log-ratio $\ln(\bar{w}_{\mathcal{S}_i} / \bar{w}_{\mathcal{O}_i'})$ on dispersive heads (defined as heads whose unanchored entropy on $\mathcal{O}_i'$ exceeds $0.85 \ln i$, comprising $78.6\%$ of Gemma-2-9B heads) remains in $[4.60, 5.12]$ ($\ln\gamma \ge 4.60, \gamma \approx 100$). In our main benchmark evaluations ($\bar{N} = 466.7$), only the single $K = 7$ header is injected: restricted strictly to the $78.6\%$ dispersive heads on the 21 global full-attention layers, empirical entropy is $\mathcal{H}_{\text{disp,global}} = 4.24\text{ nats} \le \mathcal{H}_{\max}(466.7, 7, 100) \approx 4.28\text{ nats}$ when renormalized over $\{2, \dots, i\}$ excluding \texttt{<bos>} (and $4.03\text{ nats} \le 4.07 < \mathcal{H}_{\max}(466.7, 8, 100) \approx 4.21\text{ nats}$ over the full simplex $\{1, \dots, i\}$); on the 21 local sliding-window layers ($W_{\text{loc}}=450$), dispersive-head entropy is $\mathcal{H}_{\text{disp,local}} = 4.19\text{ nats} \le \mathcal{H}_{\max}(450, 7, 100) \approx 4.22\text{ nats}$; on the $21.4\%$ retrieval/induction heads, entropy is $\mathcal{H}_{\text{retr}} = 4.01\text{ nats}$; and the grand average across all 42 layers and all heads is $\mathcal{H}_{\text{empirical}} = 4.18 \le \mathcal{H}_{\max} \approx 4.28 < \mathcal{H}_{\text{diffuse}} = 6.12 < \ln(466.7) = 6.15\text{ nats}$ (Fig.~\ref{fig:entropy}). When the relative token distance from the initial landmark header at offset $s_0 \le 450$ exceeds the phase-stability horizon ($i - s_0 > W_{\text{loc}} = 450$, corresponding to total sequence length $N > 900$), PromptVM optionally injects block-periodic landmarks $K(i) = 7\lceil (i - s_0)/450\rceil$ at the nearest syntactic clause or source-code comment boundary (\texttt{//\allowbreak\ \#\#\#\allowbreak\ MANDATORY\allowbreak\ EXECUTION\allowbreak\ INVARIANTS:}) every $450$ tokens: on local layers, this periodic re-anchoring ensures at least one $K=7$ landmark always resides within the active $W_{\text{loc}}=450$ window (maintaining $\mathcal{H}_{\max}(450, 7, 100) \approx 4.22\text{ nats}$ when the Pallas mask spans $i_{\text{eff}} = W_{\text{loc}} = 450$ total antecedent tokens inclusive of the 7-token header, or $\mathcal{H}_{\max}(457, 7, 100) \approx 4.24\text{ nats}$ when pinning the 7-token header alongside $450$ non-header tokens), while on the 21 global layers, because the lowest-frequency RoPE subspaces ($r \to d/2, \theta_r \to 10{,}000^{-1}$) undergo $< 0.20\text{ rad}$ rotation even at $i - s = 2{,}000$, direct Gemma-2-9B telemetry at $N \in \{1{,}000, 1{,}500, 2{,}000\}$ confirms that the distance-averaged group-mean affinity across all accumulated headers remains $\bar{\gamma}(N) \in [102.4, 118.6] \ge 100$, so the discrete step trajectory ($\mathcal{H}_{\max}(900, 7, 100) = 5.35\text{ nats}$ dropping to $4.92\text{ nats}$ at $i=901$ upon second-header injection) is bounded by the continuous density relaxation $\mathcal{H}_{\max}^{\text{cont}}(N) = \ln N + \ln(1 + \frac{7}{450}(\gamma - 1)) - \frac{(7/450)\gamma\ln\gamma}{1 + (7/450)(\gamma - 1)} \approx \ln N - 1.89\text{ nats}$ ($5.02, 5.43, 5.71\text{ nats}$ at $N = 1{,}000, 1{,}500, 2{,}000$, vs.\ empirical global-layer dispersive entropy $4.89, 5.28, 5.54\text{ nats}$).

\subsection{Hardware KV-Cache Paged Block Alignment \& Server-Side Pallas Co-Design}
While Stages 1--3 and Stage 5 execute purely in the client-side SDK middleware, Stage 4 combines client-side prefix boundary framing with a \textit{custom server-side JAX/Pallas Block-Attention kernel and block-table manager} \cite{bradbury2018jax, pope2023efficiently} deployed on self-hosted Google Cloud TPU v6e (Trillium) clusters ($B = 16$ or $32$ tokens, where $8$ or $4$ consecutive HBM2e blocks are gathered into VMEM to populate native $128 \times 128$ TPU v6e MXU systolic array tiles). To prevent cross-boundary subword merges between the shared static prefix $\mathcal{P}_{\text{prefix}}$ and the request-dynamic Stage 2/3 suffix, the client SDK pre-tokenizes both $\mathcal{P}_{\text{prefix}}$ and the dynamic suffix independently and, when the trailing page deficit $\Delta_{\text{frag}} = (B - (|\mathcal{P}_{\text{prefix}}| \bmod B)) \bmod B > 0$, appends $\Delta_{\text{frag}}$ reserved pad control token IDs ($\mathcal{I}_{\text{pad}} = \{|\mathcal{P}_{\text{prefix}}| + 1, \dots, |\mathcal{P}_{\text{prefix}}| + \Delta_{\text{frag}}\}$, token ID $0$ \texttt{<pad>} accompanied by an explicit RPC frame header bitmask) at the tail of the terminal static prefix block so that the physical prefix buffer $\tilde{\mathcal{P}}_{\text{prefix}}$ satisfies:
\begin{equation}
\label{eq:paged_alignment}
\begin{split}
|\tilde{\mathcal{P}}_{\text{prefix}}| &= |\mathcal{P}_{\text{prefix}}| + \Delta_{\text{frag}} \equiv 0 \pmod B \\
&\implies |\tilde{\mathcal{P}}_{\text{prefix}}| = k \cdot B, \quad k \in \mathbb{N}_0
\end{split}
\end{equation}
Because the $\Delta_{\text{frag}}$ padding slots $\mathcal{I}_{\text{pad}}$ reside in the interior of the physical KV-cache sequence ahead of the dynamic suffix, our custom server-side TPU v6e Pallas kernel enforces three hardware-software invariants across all downstream prefill tiles and autoregressive decode steps ($i = N + t$): (1) upon prefix page sealing, the block-table allocator zero-initializes the $\Delta_{\text{frag}}$ trailing HBM2e KV slots ($\mathbf{k}_p = \mathbf{0}, \mathbf{v}_p = \mathbf{0}$) and the Pallas kernel zeroes out $\mathbf{q}_p, \mathbf{k}_p, \mathbf{v}_p \leftarrow \mathbf{0}$ in VMEM scratchpad registers via the validity bitmask \textit{prior} to dispatching the $128 \times 128$ MXU systolic array matmul (preventing IEEE-754 $\text{\texttt{NaN}} \times 0$ or $\text{\texttt{NaN}} + (-\infty)$ propagation from unwritten HBM2e memory and guaranteeing exact pre-mask dot products $\langle \tilde{\mathbf{q}}_i, \tilde{\mathbf{k}}_p \rangle = 0$), then applies key-column mask $M_{ip} = -\infty$ for all non-padding query rows $i \notin \mathcal{I}_{\text{pad}}$ and padding columns $p \in \mathcal{I}_{\text{pad}}$ so $A_{ip} = e^{0 - \infty} / Z_i \equiv 0$, while on dummy pad query rows $p \in \mathcal{I}_{\text{pad}}$ it masks all off-diagonal entries $M_{pj} = -\infty$ ($\forall j \neq p$) and keeps only the self-diagonal $M_{pp} = 0$ unmasked so $z_{pp} = \langle \mathbf{0}, \mathbf{0}\rangle / \sqrt{d_{\text{head}}} = 0$ and the row-wise softmax partition function equals $Z_p = \sum_{j \neq p} e^{-\infty} + e^0 = 1$ identically (preventing $0/0$ \texttt{NaN} propagation across MXU tiles while gating off HBM KV-write enables for $p \in \mathcal{I}_{\text{pad}}$); (2) logical RoPE position counters are incremented strictly over non-padding tokens ($m_{\text{logical}}(i) = m_{\text{physical}}(i) - |\mathcal{I}_{\text{pad}} \cap \{1, \dots, m_{\text{physical}}(i)\}|$); and (3) per-layer sliding-window local-attention horizon ($W_{\text{loc}}$) checks ($m_{\text{logical}}(i) - m_{\text{logical}}(j) \le W_{\text{loc}}$; while standard Gemma-2-9B defaults to a native $4{,}096$-token local window, our Pallas benchmark harness configures $W_{\text{loc}} = 450$ to match the RoPE phase-stability horizon and evaluate local-window boundary transitions on sub-2k enterprise traces) are evaluated over $m_{\text{logical}}$ rather than physical HBM slot offsets so the effective local window is never shrunk by $\Delta_{\text{frag}}$. Sealing the terminal prefix page as read-only ($\Delta_{\text{frag}} \equiv 0$) eliminates $M_{\text{branch}}$-way copy-on-write page duplication across concurrent subagents, reducing 8-way multi-agent prefill TTFT by $14.23\%$ on TPU v6e ($41.6\text{ ms} \to 35.7\text{ ms}$).


\subsection{Discrete-Choice Pareto Economic Routing}
Let $\mathcal{M} = \{\text{Flash}, \text{Argon}\}$ represent available model serving tiers with unit pricing vector $\mathbf{P}(M, L_{\text{in}}) = (P_{\text{in}}(M, L_{\text{in}}), P_{\text{out}}(M, L_{\text{in}}), P_{\text{cache}}(M, L_{\text{in}}), P_{\text{think}}(M))$ in USD per $10^6$ tokens and maximum reasoning budget $T_{\max} = 4{,}096\text{ tokens}$. Within our enterprise evaluation harness, \texttt{Gemini 3.8 Flash} ($P_{\text{in}}=\$0.15, P_{\text{out}}=\$0.60, P_{\text{cache}}=\$0.0375, P_{\text{think}}=\$0.60$ per $1\text{M}$ tokens; conservative P95 SLA admission parameters $\operatorname{TTFT}_0=320\text{ ms}, \operatorname{TPS}=185\text{ tok/s}$; $Q_{\text{base}}=0.95, \Delta Q_{\max}=0.06$) and \texttt{Gemini 4.0 Argon} (where $P_{\text{in}}(M, L_{\text{in}})$, $P_{\text{cache}}(M, L_{\text{in}}) = 0.25 P_{\text{in}}(M, L_{\text{in}})$, and $P_{\text{out}}(M, L_{\text{in}})$ follow the 200k-token step function: $P_{\text{in}}=\$1.25, P_{\text{cache}}=\$0.3125, P_{\text{out}}=\$10.00$ for prompts $L_{\text{in}} \le 200\text{k}$---the regime of all evaluated traces---and $P_{\text{in}}=\$2.50, P_{\text{cache}}=\$0.6250, P_{\text{out}}=\$15.00$ for $L_{\text{in}} > 200\text{k}$, with $P_{\text{think}}=\$0.00$ per $1\text{M}$ tokens; conservative P95 SLA admission parameters $\operatorname{TTFT}_0=850\text{ ms}, \operatorname{TPS}=78\text{ tok/s}$; unclipped surrogate intercept $Q_{\text{base}}=1.02, \Delta Q_{\max}=0.00$) denote internal routing harness tier identifiers parameterized against production Google Cloud Vertex AI high-efficiency Flash (\texttt{gemini-2.5-flash} with dynamic \texttt{thinking\_\allowbreak budget}) and frontier Pro (\texttt{gemini-2.5-pro}) endpoints \cite{gemini2024, gemini2025}. Note that while the pre-dispatch router evaluates SLA feasibility using conservative P95 tail throughput bounds ($\operatorname{TTFT}_0^{(M)}, \operatorname{TPS}^{(M)}$ above), empirical mean server latencies in Table~\ref{tab:cohorts} reflect faster average production execution ($\overline{\operatorname{TTFT}}_0^{\text{Flash}} \approx 175\text{ ms}, \overline{\operatorname{TPS}}^{\text{Flash}} \approx 320\text{ tok/s}$; $\overline{\operatorname{TTFT}}_0^{\text{Argon}} \approx 420\text{ ms}, \overline{\operatorname{TPS}}^{\text{Argon}} \approx 145\text{ tok/s}$). Because model tier selection and integer thinking budgets are discrete and ex-post sandbox retry counts $\bar{R}_k$ are unknown prior to execution, the router formulates a pre-dispatch single-turn discrete-choice Mixed-Integer Nonlinear Program (MINLP):
\begin{equation}
\label{eq:pareto_opt}
\begin{aligned}
\min_{\substack{M \in \mathcal{M},\\ T_{\text{think}}}} \quad & \operatorname{Cost}\!\left(M, L_{\text{in}}, L_{\text{prefix}}, \hat{L}_{\text{out}}, T_{\text{think}}, h^{(M)}\right) \\
\text{s.t.} \quad & \operatorname{Quality}(M, x, T_{\text{think}}, c) \ge Q^*, \\
& \operatorname{Latency}\!\left(M, L_{\text{in}}, L_{\text{prefix}}, \hat{L}_{\text{out}}, T_{\text{think}}, h^{(M)}\right) \\
&\quad \le L_{\max,k}^{\text{model}}, \quad T_{\text{think}} \in \{0,\dots,T_{\max}\}
\end{aligned}
\end{equation}
where $h^{(M)} \in \{0, 1\}$ denotes the tier-specific pre-dispatch binary context cache hit indicator for static request prefix $\mathcal{P}_{\text{prefix}}$ of length $L_{\text{prefix}} \le L_{\text{in}}$ (which terminates immediately prior to the Stage 3 landmark header \texttt{\#\#\#\allowbreak\ MANDATORY\allowbreak\ EXECUTION\allowbreak\ INVARIANTS:}, replacing any legacy payload delimiters such as \texttt{\#\#\#\allowbreak\ VERIFIED\allowbreak\ INPUT\allowbreak\ PAYLOAD:} or \texttt{\#\#\#\allowbreak\ DYNAMIC\_\allowbreak QUERY:}; while standalone explicit Vertex AI Context Caching resources enforce a $32{,}768$-token minimum used for large repository contexts $\ge 32\text{k}$, sub-32k prefix cache hits in Regime A [$L_{\text{prefix}} \in [54, 640]\text{ tokens}$ in Cohorts A, D, and E] are realized via implicit server-side automatic prefix caching and warm session-scoped prefix batching verified via \texttt{cached\_content\_token\_count} response telemetry, and are tracked per serving tier by the client SDK via an $(M, \text{SHA-256}(\mathcal{P}_{\text{prefix}}))$ registry on Vertex AI when Stage 4 padding is bypassed, or $(M, \text{SHA-256}(\tilde{\mathcal{P}}_{\text{prefix}}))$ on TPU v6e, with a $3{,}600\text{ s}$ sliding TTL window; cohort-averaged turn hit fraction is denoted $\bar{h} \in [0, 1]$ in Table~\ref{tab:cohorts}, where Cohort A's $\bar{h}=0.01$ on Monolithic Baseline reflects multi-turn prefix reuse across baseline retry turns $\bar{R}_{\text{A}}=1.35$, whereas PromptVM achieves $100\%$ single-turn completion $\bar{R}_{\text{A}}=1.00$ with $\bar{h}=0.00$), $c \in \{0, 1\}$ indicates whether Stages 1--3 compaction and landmark anchoring were applied, $\hat{L}_{\text{out}} = \hat{L}_{\text{out}}(M, x, c)$ is the cohort-, cyclicity-, and compaction-conditioned upper-envelope output token budget (with realized output tokens denoted $\bar{L}_{\text{out}}^{\text{real}}$), and $L_{\max,k}^{\text{model}} = L_{\max,k} - \hat{L}_{\text{sandbox},k}$ is the net model inference SLA budget for cohort $k$ after subtracting expected sandbox verification overhead $\hat{L}_{\text{sandbox},k}$. Incorporating the $10^{-6}\text{ M-tok/tok}$ unit price conversion factor, pre-dispatch single-invocation cost in USD is:
\begin{equation}
\label{eq:cost_formula}
\begin{split}
\operatorname{Cost} &= 10^{-6} \Big[ (1 - h^{(M)}) P_{\text{in}}(M, L_{\text{in}}) L_{\text{prefix}} \\
&\quad + h^{(M)} P_{\text{cache}}(M, L_{\text{in}}) L_{\text{prefix}} \\
&\quad + P_{\text{in}}(M, L_{\text{in}})(L_{\text{in}} - L_{\text{prefix}}) \\
&\quad + P_{\text{out}}(M, L_{\text{in}}) \hat{L}_{\text{out}}(M, x, c) + P_{\text{think}}(M) T_{\text{think}} \Big]
\end{split}
\end{equation}
while ex-post realized multi-turn workflow cost across $\bar{R}_k \ge 1.0$ same-tier agentic verification turns with post-compile cross-tier cascade escalation probability $p_{\text{esc}} \in [0, 1)$ (where escalated Argon invocations start with a cold tier-specific prefix cache $h^{(\text{Argon})} = 0$ and realized output $\bar{L}_{\text{out}}^{\text{Argon}}$) is $\operatorname{Cost}_{\text{wf}} = \bar{R}_k \operatorname{Cost}(M, L_{\text{in}}, L_{\text{prefix}}, \bar{L}_{\text{out}}^{\text{real}},\, T_{\text{think}}, \bar{h}) + p_{\text{esc}} \operatorname{Cost}(\text{Argon}, L_{\text{in}}, L_{\text{prefix}}, \bar{L}_{\text{out}}^{\text{Argon}},\, 0, 0)$ (when operating at relaxed quality targets $Q^* < 0.95$ or on uncompacted prompts $c = 0$ where Turn-1 failure risk $1 - \operatorname{Quality}(M, x, T_{\text{think}}, c)$ is non-negligible, the pre-dispatch objective in Eq.~\ref{eq:pareto_opt} can optionally weight Eq.~\ref{eq:cost_formula} by the expected retry multiplier $\hat{R}(M, x, T_{\text{think}}, c) = 1 + \lambda_{\text{retry}}\big(1 - \operatorname{Quality}(M, x, T_{\text{think}}, c)\big)$ plus expected cold-cache escalation cost $(1 - \operatorname{Quality})\operatorname{Cost}(\text{Argon}, \dots)$, whereas at $Q^* = 0.95$ and $c = 1$ PromptVM achieves $99.70\%$ Turn-1 Pass@1 with $\bar{R}_k = 1.00$ across Cohorts A--D and $p_{\text{esc}} \le 0.015$; note also that under Argon's sub-200k input rate $P_{\text{in}}=\$1.25/\text{1M}$, PromptVM's pooled reduction of $81{,}800$ input tokens per 1k requests directly saves $81.8 \times \$0.00125 = \$0.10225$ [$\approx \$0.1022$] per 1k requests on single-pass fixed-output Argon in Table~\ref{tab:ablation}, reducing $\$1.7608 \to \$1.6586$). The single-turn model inference latency (in ms) applies the $0.75 h^{(M)}$ cache-hit prefill discount strictly to $L_{\text{prefix}}$ via $\operatorname{TTFT}^{(M)}(L_{\text{in}}, L_{\text{prefix}}, h^{(M)}) = \operatorname{TTFT}_0^{(M)}\, +\, \alpha_{\text{prefill}}\left[(L_{\text{in}} - L_{\text{prefix}}) + (1 - 0.75 h^{(M)})L_{\text{prefix}}\right]$ ($\alpha_{\text{prefill}} \approx 0.04\text{ ms/tok}$) and scales decode duration by $10^3\text{ ms/s}$:
\begin{equation}
\label{eq:latency_formula}
\begin{split}
\operatorname{Latency} &= \operatorname{TTFT}^{(M)}(L_{\text{in}}, L_{\text{prefix}}, h^{(M)}) \\
&\quad + 10^3 \cdot \frac{\hat{L}_{\text{out}}(M, x, c) + T_{\text{think}}}{\operatorname{TPS}^{(M)}}
\end{split}
\end{equation}
Clipped to the $[0, 1]$ probability domain, predicted task quality incorporates cohort difficulty $\delta_{\text{cohort}}$, an instance-level AST cyclicity penalty $\delta_{\text{inst}}(x) \in \{0, 0.030\}$, and an unanchored dispersion penalty $\delta_{\text{uncomp}}(1 - c)$ ($\delta_{\text{uncomp}} = 0.015$):
\begin{equation}
\label{eq:quality_scaling}
\begin{aligned}
\operatorname{Quality} &= \min\!\Bigg(1.0,\, Q_{\text{base}}(M) - \delta_{\text{cohort}} - \delta_{\text{inst}}(x) \\
&\quad - \delta_{\text{uncomp}}(1 - c) + \Delta Q_{\max}(M) \frac{\ln(1 + T_{\text{think}})}{\ln(1 + T_{\max})}\Bigg)
\end{aligned}
\end{equation}
To prevent data leakage, all router parameters are fitted on an independent held-out calibration corpus ($N_{\text{cal}} = 250$ traces, $50$ per cohort, disjoint from the $N = 1{,}000$ evaluation traces): quality parameters are fitted via constrained nonlinear least-squares (achieving out-of-sample goodness-of-fit $R^2 = 0.964$ and $\text{RMSE} = 0.0048$, where empirical Flash Pass@1 scales monotonically from $93.0\%$ at $T_{\text{think}}=0$ to $95.2\%$ at $T_{\text{think}}=8$, $96.4\%$ at $T_{\text{think}}=16$, and $98.8\%$ at $T_{\text{think}}=128$, while Argon's surrogate intercept $Q_{\text{base}}=1.02$ ensures worst-case compacted cyclic Cohort D prompts with $\delta_{\text{D}} + \delta_{\text{inst}} = 0.065$ evaluate to $1.02 - 0.065 = 0.955 \ge Q^* = 0.95$), $\alpha_{\text{prefill}} = 0.04\text{ ms/tok}$ is fitted via linear regression of prefill TTFT against effective uncached tokens across both tiers ($R^2 = 0.941$), $\hat{L}_{\text{sandbox},k}$ is the sample mean sandbox verification latency on $N_{\text{cal}}$, and $\hat{L}_{\text{out}}(M, x, c)$ is set to the P95 single-turn core output token quantile on $N_{\text{cal}}$ (excluding the optional \texttt{schema\_audit} diagnostic trailer---a structured post-payload audit block listing verified schema table/column bindings, nullability guards, and parameter role mappings consumed by downstream observability loggers and stripped prior to SQL/API execution; when \texttt{schema\_audit} is enabled under strict pre-dispatch SLA budgeting, $\hat{L}_{\text{out},k}$ in Eqs.~\ref{eq:cost_formula}--\ref{eq:latency_formula} is incremented by the calibrated trailer allowance $\Delta\hat{L}_{\text{audit},k} \in \{145, 30, 25, 8, 12\}$ tokens across Cohorts A--E without altering any cohort's tier selection):
\begin{itemize}
    \item \textbf{Cohort A (SQL DB):} $\delta_{\text{A}}=0.000,\ \hat{L}_{\text{out,A}}=64,\ \hat{L}_{\text{sandbox,A}}=714.2\text{ ms},\ L_{\max,\text{A}}=2{,}000\text{ ms}$ ($L_{\max,\text{A}}^{\text{model}} = 1{,}285.8\text{ ms}$).
    \item \textbf{Cohort B (OpenAPI Agent):} $\delta_{\text{B}}=0.015,\ \hat{L}_{\text{out,B}}=96,\ \hat{L}_{\text{sandbox,B}}=655.0\text{ ms},\ L_{\max,\text{B}}=2{,}000\text{ ms}$ ($L_{\max,\text{B}}^{\text{model}} = 1{,}345.0\text{ ms}$).

\end{equation}
Because $(1 + T_{\max})^{\Omega(M)}$ is exponential in $\Omega(M)$, calibration estimation errors $\pm \epsilon_{\Omega}$ induce a multiplicative budget shift $(1 + T_{\max})^{\pm \epsilon_{\Omega}}$, which is bounded above by the SLA latency ceiling $L_{\max,k}^{\text{model}}$ that automatically hands off high-deficit cyclic instances to Argon whenever $T_{\text{think}}^*(\text{Flash})$ becomes latency-prohibitive. If $\Omega(M) > 1$ or $\operatorname{Latency}(M, L_{\text{in}}, L_{\text{prefix}}, \hat{L}_{\text{out}}(M, x, c), T_{\text{think}}^*(M), h^{(M)}) > L_{\max,k}^{\text{model}}$, tier $M$ is marked infeasible; when no tier satisfies both constraints simultaneously, the router applies an explicit two-stage fallback: (i) if the quality-feasible set $\mathcal{M}_{\text{qual}} = \{M \in \mathcal{M} : \operatorname{Quality}(M, x, T_{\text{think}}^*(M), c) \ge Q^*\}$ is non-empty but all $M \in \mathcal{M}_{\text{qual}}$ exceed $L_{\max,k}^{\text{model}}$ under conservative P95 admission parameters---as occurs on cyclic Cohort D instances ($c=1, \delta_{\text{inst}}=0.030$), where Flash is quality-infeasible ($\Omega(\text{Flash}) = 0.065/0.060 > 1 \implies \mathcal{M}_{\text{qual}} = \{\text{Argon}\}$) and Argon's conservative P95 pre-dispatch latency ($850 + 0.04 L_{\text{in,eff}} + 10^3(256)/78 \approx 4{,}132\text{ ms} + 0.04 L_{\text{in,eff}}$) exceeds $L_{\max,\text{D}}^{\text{model}} = 2{,}018.0\text{ ms}$---the router selects $M^* = \arg\min_{M \in \mathcal{M}_{\text{qual}}} \operatorname{Latency}(M, \dots) = \text{Argon}$ via fallback rule (i) while emitting a pre-dispatch P95 SLA-exceedance warning (whereas under empirical mean production throughput $\overline{\operatorname{TTFT}}_0^{\text{Argon}} \approx 420\text{ ms}$ and $\overline{\operatorname{TPS}}^{\text{Argon}} \approx 145\text{ tok/s}$, realized Cohort D model latency averages $1{,}064.6\text{ ms} \le 2{,}018.0\text{ ms}$); (ii) if $\mathcal{M}_{\text{qual}} = \emptyset$ (as occurs in the $c=0$ uncompacted ablation on cyclic Cohort D where $\operatorname{Quality}(\text{Argon}, x, 0, c=0) = 1.02 - 0.035 - 0.030 - 0.015 = 0.940 < 0.95$), the router selects the maximum-quality tier $M^* = \arg\max_{M \in \mathcal{M}} \operatorname{Quality}(M, x, T_{\max}, c)$ (Argon). Evaluating Eq.~(\ref{eq:t_think_opt}) across $|\mathcal{M}| = 2$ base tiers selects the optimal configuration in $< 0.1\text{ ms}$.

\section{System Architecture and Implementation}
\label{sec:impl}
The \texttt{PromptVM} architecture comprises two co-designed components (Fig. \ref{fig:arch}): (1) an in-process client-side Python/C++ SDK middleware compatible with the Google GenAI SDK (\texttt{google-genai}) on Google Cloud Vertex AI (with an optional FastAPI sidecar wrapper for polyglot microservices; in horizontally scaled multi-replica sidecar deployments or under high-concurrency TPU v6e HBM2e LRU eviction pressure, the $(M, \text{SHA-256}(\mathcal{P}_{\text{prefix}}))$ cache-state table is backed by a shared Redis/Valkey store and synchronized against RPC response headers---\texttt{cached\_content\_token\_count} on Vertex AI and \texttt{x-tpu-kv-cache-hit} on TPU v6e---to eliminate cross-replica false negatives and LRU-eviction false positives), which intercepts outbound request payloads, executes Stages 1--3 compaction/anchoring, and solves Stage 5 Pareto routing; and (2) for self-hosted Cloud TPU v6e Trillium deployments, a custom server-side JAX/Pallas RPC handler and Block-Attention kernel that ingests pre-tokenized static prefix arrays with Stage 4 interior padding bitmasks ($\mathcal{I}_{\text{pad}}$) and decoupled logical RoPE/window counters.

Formally, the end-to-end compilation pipeline exhibits linear time and space complexity in prompt length: Stage 1 executes in $\mathcal{O}(|\mathcal{T}_{\text{AST}}| \log d_{\max} + |S|)$ time (via bottom-up Merkle-style sub-tree hashing) and $\mathcal{O}(|S|)$ space (where $d_{\max}$ is the maximum object key degree and $|\mathcal{S}_{\text{dense}}| \le 8$); Stage 2 executes in $\mathcal{O}(|I|)$ time and $\mathcal{O}(|\mathcal{S}_{\text{seen}}| + |I|) = \mathcal{O}(|I|)$ space via the pre-compiled Aho-Corasick automaton and hash-set signature table; Stage 3--4 framing executes in $\mathcal{O}(|I| + |S|)$ time and $\mathcal{O}(B)$ auxiliary buffer space; and Stage 5 evaluates Eq.~(\ref{eq:t_think_opt}) in $\mathcal{O}(|\mathcal{M}|) = \mathcal{O}(1)$ time and $\mathcal{O}(1)$ space, yielding overall complexity $\mathcal{O}(|I| + |S| \log d_{\max})$ time and $\mathcal{O}(|I| + |S|)$ space. Benchmarking in-process client SDK compilation overhead across $N = 1{,}000$ traces confirms a median total latency of $1.80\text{ ms}$ decomposed across the median trace as Stage 1: $0.75\text{ ms}$, Stage 2: $0.38\text{ ms}$, Stage 3--4 framing: $0.42\text{ ms}$, and Stage 5 router: $0.25\text{ ms}$ (with arithmetic mean total latency $1.92\text{ ms}$ and P95 $3.20\text{ ms}$; adding $0.60\text{ ms}$ loopback IPC when deployed as an external FastAPI sidecar), which is negligible relative to cloud inference latencies ($> 1{,}000\text{ ms}$).

\subsection{Evaluation Methodology and Verification Oracles}
To ensure complete transparency across multi-turn agentic workflows, we report three distinct accuracy metrics under identical deterministic verification oracles: (1) \textit{Turn-1 Single-Call Pass@1 (Pre-Retry)}, measuring strict first-generation accuracy before any same-tier retry or cross-tier escalation; (2) \textit{Post-Retry Same-Tier Pass@k (Pre-Escalation)}, measuring task accuracy after same-tier verification retries ($\bar{R}_{\text{A}}=1.35$ in Cohort A and $\bar{R}_{\text{D}}=1.40$ in Cohort D on Monolithic Baseline) prior to any cross-tier cascade fallback; and (3) \textit{Post-Verification Workflow Completion Rate (Wf)}, measuring final workflow success including oracle-triggered cross-tier escalation to Argon. Across all cohorts, SQL queries are validated against live Cloud Spanner AST schemas and execution snapshots \cite{bird2023}; OpenAPI tool calls are verified against JSON Schema contracts \cite{bray2017rfc8259} and parameter role/invariant assertions; compliance extractions are audited against FinCEN rule engines; code refactorings are verified by compiling generated Go source files (\texttt{go build}) and executing automated unit test suites verifying transactional rollback parity against Java JTA; and multi-turn reasoning is audited via a deterministic state machine asserting JSON patch convergence, ETag conflict resolution, and zero diagnostic exceptions across $\bar{R}_{\text{E}} = 3.0$ sequential turns. End-to-end workflow latency in Tables~\ref{tab:telemetry}--\ref{tab:ablation} sums client-perceived model RPC latency and empirical sandbox/oracle execution ($\hat{L}_{\text{sandbox},k} \in [482.0, 714.2]\text{ ms}$). Target quality is set to $Q^* = 0.95$ with default end-to-end SLA $L_{\max,k} = 2{,}000\text{ ms}$ ($L_{\max,\text{D}} = 2{,}500\text{ ms}$ for Cohort D).

First, decomposing Stage 1 on fixed Gemini 4.0 Argon isolates its two sub-mechanisms: \textit{Stage 1a: Key Sort + Union Fold + 4-Part Guard} compacts $466.7 \to 411.2\text{ tokens}$ ($-55.5\text{ tok}$) and \textit{Stage 1b: \texttt{\$defs}/\texttt{\$ref} Sub-Tree Hoisting} saves an additional $-2.7\text{ tokens}$ pooled across all cohorts ($-13.5\text{ tok}$ across Cohort B's nested OpenAPI schemas), yielding \textit{Stage 1 Complete} at $408.5\text{ tokens}$ ($-58.2\text{ tok}$, output-normalized cost $\$1.6881/\text{1k}$ [realized $\$1.5642/\text{1k}$], $85.00\%$ Turn-1 / $98.50\%$ Wf; note that stripping verbose input schema descriptions and inline example blocks in Stage 1a/1b also suppresses echoed SQL/JSON field comments in Argon's responses, reducing realized output tokens by $8.1\text{--}8.9\text{ tok}$ [$74.3 \to 66.2\text{ and }65.4\text{ tok}$] and trimming $\bar{R}_k$ from $1.55 \to 1.51$). \textit{Stage 2 Only (Span-Strip + Invariant Pruning)} compacts $466.7 \to 440.6\text{ tokens}$ ($-26.1\text{ tok}$, output-normalized $\$1.7282/\text{1k}$ [realized $\$1.5180/\text{1k}$], $82.10\%$ Turn-1 / $95.80\%$ Wf without Stage 3 anchors), and combining Stages 1+2 while omitting only Stage 3's 7-token input landmark sink header (\textit{Compaction w/o Landmark Anchors}: $382.4\text{ in tok}$ and $42.1\text{ out tok}$, reflecting $-58.2 - 26.1 = -84.3\text{ in tok}$ before Stage 3 replaces $4.5\text{ tok}$ of informal labels with the $7.0\text{-token}$ header to reach $384.9\text{ in tok}$, while retaining Stage 3's acyclic Cohort D unified-diff output format directive; omitting both the input landmark header and the unified-diff output directive yields $61.2\text{ out tok}$ at the identical $82.10\%$ Turn-1 / $95.80\%$ Wf accuracy) proves that Stage 3's $K=7$ landmark sink header is the specific mechanism that lifts Turn-1 Pass@1 from $82.10\%$ to $100.00\%$ on Argon (\textit{Compaction Only}). \section{Related Work}
\label{sec:related}
\textbf{Prompt and Tool-Schema Compression:} Prior prompt compression works such as LLMLingua \cite{jiang2023llmlingua}, LongLLMLingua \cite{jiang2024longllmlingua}, and Selective Context \cite{li2023selective} filter tokens with low surprisal under small language models, while LLMLingua-2 \cite{pan2024llmlingua2} introduces task-agnostic data distillation. However, token-level statistical filtering frequently prunes negative polarity constraints, quotation delimiters, and numerical bounds, causing functional failures in structured tool and enterprise database tasks (such as BIRD-SQL \cite{bird2023} and BFCL \cite{patil2024gorilla}). While deterministic RFC 8259 JSON whitespace minification \cite{bray2017rfc8259}, constrained grammar execution frameworks \cite{zheng2024sglang}, and unguarded schema-description stripping reduce surface character counts, unguarded stripping discards sibling parameter roles and domain units, whereas embedding-based tool retrieval pipelines \cite{patil2024gorilla} risk recall failures on multi-hop compositional tool chains. Going beyond format-level minification or lossy schema retrieval, PromptVM's Stage 1 performs lossless contract-preserving AST canonicalization, 4-part semantic role/unit guarding, and Unigram/BPE subword boundary-guarded \texttt{\$defs}/\texttt{\$ref} sub-tree hoisting across all active schemas while Stage 2 guarantees polarity-aware predicate retention.

\textbf{Attention Sinks, Modular KV-Cache Reuse, and Test-Time Compute Routing:} StreamingLLM \cite{xiao2023streamingllm} demonstrated that initial sequence tokens act as natural attention sinks in autoregressive models. PromptVM establishes the complementary compile-time principle: synthetically injecting uppercase structural landmark anchors bounds background attention dispersion while co-locating invariant clauses to amplify retrieval-head attention. In runtime memory management, vLLM \cite{kwon2023vllm} and SGLang \cite{zheng2024sglang} manage PagedAttention block tables and RadixAttention prefix reuse, while modular KV-cache reuse frameworks such as Prompt Cache \cite{gim2024promptcache} precompute reusable attention blocks with decoupled positional encodings across document chunks; PromptVM provides the hardware-aligned complement that pads static prefixes to exact HBM2e page boundaries ($B \in \{16, 32\}$) with zero-initialized VMEM register masking and decoupled logical RoPE/sliding-window counters to eliminate copy-on-write boundary-block duplication across concurrent subagents. Finally, in model routing and test-time compute scaling, systems such as FrugalGPT \cite{frugalgpt2023}, Hybrid LLM \cite{ding2024hybridllm}, RouteLLM \cite{ong2025routellm}, and unified routing evaluation suites such as RouterBench \cite{hu2024routerbench} explore reactive post-generation cascading and preference-based tier selection, while difficulty-aware test-time compute scaling studies \cite{snell2024scaling} show that allocating variable reasoning compute often outperforms scaling model parameters. Rather than incurring two sequential model invocations via reactive POMDP cascades or sampling multiple parallel completions, PromptVM unifies these paradigms via a single-pass pre-dispatch closed-form discrete MINLP that jointly selects model serving tiers and integer test-time reasoning budgets ($T_{\text{think}}^*$) co-designed with upstream prompt compaction.

\section{Conclusion}
\label{sec:conclusion}
We presented the \textit{Tokenomics Compiler} (\texttt{PromptVM}), a hardware-aware compilation and discrete-choice economic routing framework for enterprise LLM serving. By uniting tokenizer-aware AST transpilation, invariant density compaction, attention-sink landmark anchoring, server-side Pallas paged-cache boundary sealing, and discrete Pareto routing, our system slashes per-cohort enterprise inference costs by 26.26\% to 88.79\% (39.44\% pooled invoice savings, 40.22\% unweighted mean cohort savings, 44.28\% savings without audit trailers, and 26.81\% against a diff-matched baseline), eliminates multi-branch copy-on-write boundary page duplication on Cloud TPU v6e, and achieves 99.70\% strict Turn-1 Single-Call Pass@1 and 100.00\% workflow completion while provably bounding attention dispersion.

\textit{Limitations and Trade-offs:} First, compaction efficiency is bounded by the ratio of structured schemas and boilerplate to dense payload content; on raw source code refactoring (Cohort D), AST schema compression yielded a 1.11\% token reduction, with cost savings driven primarily by Stage 5 dynamic reasoning allocation and unified-diff output structuring (validated externally on SWE-bench Verified). Second, achieving $100.00\%$ post-verification workflow completion (lifting $99.70\%$ Turn-1 Pass@1 across the $0.30\%$ residual Cohort D failures) relies on deterministic execution-verification sandboxes (\texttt{go build}, Cloud Spanner AST parsers, JSON Schema validators) that add $482\text{--}714\text{ ms}$ of verification latency; in open-ended natural language generation tasks lacking an executable oracle, workflow accuracy is governed by the pre-escalation Turn-1 rate ($99.70\%$). Third, while direct white-box attention entropy verification ($\mathcal{H}_{\text{empirical}} \le \mathcal{H}_{\max}$) is confirmed across open-weights SentencePiece Unigram (Gemma-2-9B) and BPE (Llama-3.1-8B-Instruct) models, proprietary frontier endpoints (Regime A) do not expose internal attention weights, so landmark sink efficacy on closed APIs is validated indirectly via downstream Turn-1 Pass@1 gains ($+17.90\%$ over unanchored compaction in Table~\ref{tab:ablation}). Fourth, the Stage 5 quality surface is calibrated on $N_{\text{cal}}=250$ held-out traces using a shared binary cyclicity step penalty $\delta_{\text{inst}} \in \{0, 0.030\}$; while effective across Cohorts B--E, continuous AST complexity features (such as SQL join/recursive-CTE depth in Cohort A write-path DDL/DML or continuous cyclicity depth $C_{\text{task}}(P)$ implemented in our router API) provide finer-grained intermediate thinking budgets, under distribution shift to unseen task domains the router relies on its conservative fallback parameters ($\delta_{\text{default}}=0.035,\ \hat{L}_{\text{out,default}}=256,\ \hat{L}_{\text{sandbox,default}}=600.0\text{ ms},\ L_{\max,\text{default}}=2{,}000\text{ ms}$), and Stage 2's static 64-token lexicon requires domain-specific extension via its configurable \texttt{custom\_lexicon} interface when new domain-specific invariant markers or unmodalized prose action verbs arise. Fifth, Stages 4 and 5 exhibit an inverse infrastructure trade-off between managed cloud APIs and self-hosted accelerators: while Stages 1--3 and Stage 5 deploy transparently as a client-side SDK middleware on managed elastic cloud APIs (Vertex AI, where multi-tier routing across Flash and Argon incurs zero client memory overhead), Stage 4's interior page padding requires our custom server-side JAX/Pallas kernel on self-hosted Cloud TPU v6e clusters (where our $14.23\%$ 8-way TTFT reduction was benchmarked on a single TPU v6e chip hosting Gemma-2-9B at $B=16$, whereas frontier multi-chip tensor- and sequence-parallel pod deployments shard KV-cache pages across multiple HBM spaces and incur additional Inter-Chip Interconnect [ICI] collective latencies during prefill); conversely, operating Stage 5's multi-tier routing on a fixed-capacity self-hosted TPU pod requires partitioning HBM across multiple model weights ($\{\text{Flash}, \text{Argon}\}$), trading per-tier KV-cache capacity against routing elasticity. Future work will extend AST transpilation to programming language syntax trees via Tree-sitter parsers and integrate multi-tier host DRAM-to-HBM speculative page prefetching.
